## 1. 一句话与背景

**一句话**：3.8 = 3.7「自动执行驾驶舱」范式转型的未竟部分——把驾驶舱从「对话门后半程」推到**全程**（前半程生成入口/Provider 配置/流式进度），并把「连接」与「运行」从纠缠中解出来（断连不再污染运行终态、恢复链可达）。

背景链条：

- 3.7 确立的范式 = **自动执行为主 + 异常驱动人工**（exception-driven 驾驶舱，用户拍板，台账:L455）。四个 Phase（1a 协议补齐与三区只读 → 1b 全局 shell/聚合/就地动作/autopilot/四层提醒 → 2 编码仪表盘 → 3 计划审批 → 4 advance/接管操作收口）已全部代码侧收官（台账:L460/L463/L470/L472/L487），全量 166 文件 / 1401 tests + tsc 0，引擎零改动。
- 2026-09-16 全天：P4 代理预检+补验（台账:L489-490）→ 用户验收全程，中途发现跨形态切换断头并裁决「类型感知默认」（台账:L492-495）→ 断连三案 RCA 定案（台账:L496）→ stale-close 热修部署 v16h → **用户最终链验证通过**（issue→生成→门点 1 次确认→advance→coding 点 1 次开始→落地，标准已获用户确认，台账:L497）。
- 验收同时暴露三条结构性欠账，即 3.8 的三个主攻面：
  1. **前半程入口**：生成发起/Provider 配置/生成过程可视仍缺位于 legacy，cockpit 只覆盖「生成开始之后」的门与执行流（本文 §2-M1/M4）；
  2. **连接韧性**：断连与运行生命周期纠缠——前端 stale-close 误杀已热修，但 socket 清理误标 run 终态、idle 90-95s 独立风险、归因缺口仍在（§2-M2）；
  3. **恢复链**：断连/中止后的快照门 confirm 被引擎恢复链缺口阻断（0429 形态），投影层无引擎终态守卫（0017 形态）（§2-M3）。

### P2 连接解耦：run 生命周期与连接脱钩（RCA:§5 根治设计）

引擎侧结构性改造，RCA §5 原文四条：

1. **run = session-owned durable entity**：run manager 持有单一 engine、run token、provider-drive、状态机与完成/取消原因；不再由 socket-local `current_run` 代表 run 所有权。
2. **驱动/观察者协议显式化**：协议（Hello）显式区分 `driver`（带 lease/命令权限）与 `observer`（只读）；observer 不可发送改变 run 的消息；driver 断开只撤销 lease 或记录状态，不取消/不改写 run。（现状：driver/observer 只是前端用途约定，任一同 endpoint 连接都可发业务命令，RCA:§1.2）
3. **连接关闭不写 `aborted_by_disconnect`**：只有 provider token 实际被取消、provider 失败或明确人类 abort 才写对应终态（消除 M2-2 误标）。
4. **重连 cursor 重订阅 + 广播**：重连用 event cursor / durable snapshot 重新订阅；tab/代理/网络短暂断连不再污染运行终态。顺带根治 M2-5/M5-1（被动连接实时事件盲区→session 级广播）。

- **依赖**：独立可先行（与 P1 并行）；触及 run 注册、engine 实例所有权、命令仲裁、重连回放、多连接并发——RCA §5 明示风险：「不能伪装成改一条 timeout 的补丁」。
- **预估**：2-3 个工作日（含 OpenSpec 四件套与 §6 验收矩阵真跑）。
- **验收口径**：直接采用 RCA:§6 最小验收矩阵四条——①intensive-throttling flag 下 tab 隐藏超阈值：25s ping 实际间隔/服务端不误关/run 持续且无 `aborted_by_disconnect`；②human-gate 静默>60s：前端不自关 4000、服务端不 idle close、终态=业务结果；③人为 server idle/前端 4000/页面卸载 1000/TCP drop 各一次：日志唯一归因+durable terminal reason 各自正确；④driver+cockpit observer 多连接：关 observer 对 driver run 零影响，driver close 只影响订阅/lease，run 持续。

### P3 恢复链：守卫与误标修复（可与 P2 同 PR 族）

| 项 | 内容 | 依据 |

| socket 清理不误标业务终态 | 断连清理路径不再把活动节点标 Failed/覆盖业务终态（0437 形态；P2 落地后此项被架构吸收，但可先行独立热修） | M2-2/M3-0437 |
