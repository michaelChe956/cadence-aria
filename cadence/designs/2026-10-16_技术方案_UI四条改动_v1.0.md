## 2. 删除入口收敛

### 现状核查结论
- 单删(独立 DELETE API, group 场景警告「整轮授权失效」)、Coding 页全量、生命周期抽屉全量=**三个入口, 后两个范围相同, 单删范围不同; 不能认定单删后端能力纯冗余**
- web/src 范围内未见删除动作埋点依赖(非使用率为零证据)
- 生命周期抽屉清理入口存在理由: 失效 plan 仍可达, 避免无法进 Attempt 时无处清理(IssueLifecycleWorkbenchDrawer.tsx:60-65)

### 选项(交 owner 拍板, 方案不代选)
| 选项 | 内容 | 量 |
|---|---|---|
| A 纯删单删按钮 | 移除顶栏入口+不可达前端逻辑; 保留两处全量入口 | S; 须明确是否含独立 WI 清理路径 |
| B 单删收为二级项 | 主入口只留全量; 二级项显范围+授权失效警告 | S |

任何选项: 不删服务端 Attempt DELETE 端点; 不动 command_id/expected_generation/确认分级语义; 生命周期抽屉「清理剩余」出口必须保留或完整迁入; 独立 WI 删除被关联 workspace 拒绝的规则不变。

## 3. 分诊/choice 统一进待处理抽屉

### 概念澄清(勿误合并)
- 实体详情抽屉(Story/Design/Plan 内容阅读, IssueLifecycleWorkbenchDrawer)≠ 待处理抽屉(Cockpit 人工动作收件箱 CockpitInboxDrawer)
- 改造对象=后者提升为共享宿主; **不新增消息中心或第二份待办数据库**

### 最小统一模型(扩展现有 CockpitInboxItem, 不新建 Task 模型)
- 作用域: 显式 projectId/issueId+session/Attempt 地址
- 规范身份: 完整作用域+来源类型+choiceId/gateId 归一(不得仅用 choiceId 或解析 item.id 猜地址)
- 通知身份(现有 codingAttentionIdentity)负责提醒去重, 规范身份负责跨来源合并, 两者不混
- 可操作详情: choice 题目/run、gate available_actions、版本与加载态; 本地命令态按规范身份存(提交中/等回执/失败/失效/command 谱系)

### 数据源合并
1. 目录层复用现有 observer(gate/choice 投影 + lifecycle coding_attention_items + 恢复/错误项原分组)
2. **attention 是目录, snapshot 是操作详情**: 打开/选中时按完整 Attempt 地址拉 getCodingAttemptSnapshot, 同 Attempt 复用一次, 按 focus 精确匹配补齐——不是新增 choice 卡再留同义通知卡
3. 不用「当前 session 最新活跃 Attempt」捷径替代全 Issue 目录(覆盖不了多仓多 Attempt)
4. 回执后走既有 lifecycle invalidation; 拉取失败保留目录项就地报错; 收起保留未提交表单; 打开/查看/关闭≠完成

### 兼容能力 4(choice 逐题 REST)
复用现有协议与 hook(useCockpitChoiceRespond): 保留 answers[] 结构/expected_run_id 精确绑定(缺失只读提示)/同命令同 payload 重试/202 保卡复查/expired 不转投; hook 对 sessionId 的默认依赖改显式作用域; **不退回 WS choice_response, 不加第二套提交协议**。

### 分诊卡直接操作
同一 coding_action 行内复用 CoderTriageCard(不复制三按钮); 用 postCodingGateResponse(无需挂 Coding socket); extra_context 原样传; **expected_version 必须来自服务端版本事实(listVerificationTriageRecords 的 attempt_version), 不能用 rework_count 冒充**; 托管终止继续走整 plan 终止确认面; 非当前会话动作遵守原驱动权规则。

### 兼容能力 6(通知同源提醒)
保留 display/count/notificationCandidates 三分; 通知/toast/告警只提醒+定位(点击开抽屉聚焦, 不执行动作); 详情补齐/开合/切页不产生新通知身份; 完成信息不计入待处理数; 不引入本地「已读即删除」(durable 事实关闭才是收敛)。

### 风险与验收
重复计数/跨项目同名冲突/旧回执污染/「通知到达≠可执行」。验收至少: 同一 choice 双来源只显示计数一次; 不开 Coding 页也能答 choice/处理分诊; 多仓多 Attempt 全可见; 多题/202/410/重试不退化; 版本过期/门已关/无活跃 run 失败关闭就地反馈; 通知点击只开抽屉。
