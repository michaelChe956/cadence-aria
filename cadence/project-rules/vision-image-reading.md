# 识图规则（vision 通道优先）

> 适用：所有会话（主会话与 subagent）。用户已在本机配置 vision 视觉模型。

## 规则

1. **识图第一步就是 `read <图片路径>?q=<具体问题>`**——这是 harness 内置 vision 通道（图片路由到已配置的视觉模型，返回文字答案），任何会话模型可用，支持 webp。不要先尝试其他路径。
2. **`?q=` 的问题要具体**：要求逐字摘录文字、说明颜色/徽标/尺寸/布局，一次问全，避免多轮往返。
3. **MCP 视觉工具（zai/minimax）只作兜底**：`?q=` 失败后才用。注意 zai 只接受 jpg/jpeg/png；贴图常为 webp，需先转换（本机无 ffmpeg/sharp，转换成本高）。
4. **随图附带的自动文字描述不可靠**：会话模型不支持图片输入时，消息里附的图片描述可能是整段幻觉（例如把 UI 截图描述成无关物体）。一律忽略，只信 `?q=` 的返回。
5. 会话模型本身支持图片输入时，直接内联看图，无需 `?q=`。

## 背景记录

2026-09-22 会话实录：用户贴 3 张 UI 截图（webp），会话模型不吃图；先试 zai MCP（设备名错→参数名错→webp 被拒），本机又无 ffmpeg/sharp，绕三步全死。最后 `read local://xxx.webp?q=` 一次成功。本规则把该顺序固化为强制。
