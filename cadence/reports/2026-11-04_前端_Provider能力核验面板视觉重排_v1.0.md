## 1. 结论摘要

owner 否掉的两种形态（①2×2 方格卡片 ②一整行文字流）都已避开。当前形态：

- 每家 provider 一个**块**，块之间用 **1px 分割线**（`--aria-line`）分隔；**块自身没有圆角边框卡片壳**。
- 块内**固定三行**，行1 用 grid 两端对齐、行2 是胶囊行、行3 左维度胶囊 + 右操作按钮。
- 窄容器（抽屉 ~535px / 375px 视口）下行3 用 `flex-wrap` 整体换行，**维度胶囊仍保持一行**，绝不退化成连续文字流。
- 所有状态都是 **rounded-full 胶囊**，所有操作按钮都是**次按钮**（`btn-secondary`），无 emoji、无 hover scale/位移、无粗深边框。

## 4. 断言调整 + 新增结构断言

### 4.1 调整（**只换断言对象，不弱化语义**）

| 原断言 | 调整后 | 理由 |
|---|---|---|
| `expect(providerRow.className).not.toContain("rounded")` / `not.toContain("border")` | **原样保留**（分割线改挂在 `ul` 上 ⇒ 块自身确实没有圆角边框壳，断言对象语义反而更准） | 「不要圆角边框卡片壳」这条约束更强地成立 |
| `expect(list.className).not.toContain("grid-cols-2")` | **原样保留** | 2×2 方格卡片仍未回来 |
| `expect(screen.getAllByRole("listitem")).toHaveLength(4)` | **原样保留** | 仍是 4 家 provider 一组行级列表（无嵌套列表） |
| `provider-capability-status-<type>` / `-<aspect>` / `-<type>-version` 等文案断言（`toBe("已确认")` / `toBe("未核验")` / `toBe("拒绝")` / `toBe("未探测")`） | **原样保留**，断言元素改到新结构里的同一语义节点 | 胶囊化后文案逐字未变 |

## 6. 边界与遗留（不在本次可改文件内，未擅自改动）

   且未带 `focus-visible` 焦点环 —— 属该文件范围，请该文件 owner（或 Main）顺手对齐。
3. 作用域说明「逐 LC 核验：会真实跑一次探测，可能几分钟，消耗 provider 额度。」**一字未改**（按 Main 交待，等全局化 change 落地时再改口径）。
