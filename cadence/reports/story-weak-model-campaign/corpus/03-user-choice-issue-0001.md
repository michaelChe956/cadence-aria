**标题：验证专用：新增 JavaScript 紧凑时长格式化库函数及演示页面**

**背景：**
需要一个可复用、无副作用的 JavaScript 库函数，将秒数格式化为紧凑且稳定的时长字符串；同时提供一个轻量前端演示页面，方便在浏览器中直观验证该函数的格式化效果。

**需求：**

1. 库函数

   新增并导出函数：

   `formatCompactDuration(totalSeconds)`

   格式规则：
   - 小于 1 小时：输出 `MM:SS`。
   - 大于等于 1 小时：输出 `HH:MM:SS`。
   - 分钟和秒必须补零到两位。
   - 小时不限制宽度。
   - 输入仅考虑非负安全整数；其他输入不在本次范围内。

2. 前端演示页面

   新增一个独立静态页面（纯 HTML/CSS/JavaScript，不引入框架、构建工具或第三方依赖），用于演示库函数效果：
   - 提供秒数输入框，实时展示 `formatCompactDuration` 的格式化结果。
   - 页面上静态展示全部验收示例（输入值与期望输出），并标注实际输出是否通过，便于人工核对。
   - 页面通过 JavaScript 模块方式直接引用库函数文件，保证演示用的就是真实实现，而非复制粘贴的副本。
   - 页面可用浏览器直接打开（任意静态服务器均可），无额外运行步骤。

**验收示例：**
- `formatCompactDuration(0)` === `"00:00"`
- `formatCompactDuration(1)` === `"00:01"`
- `formatCompactDuration(65)` === `"01:05"`
- `formatCompactDuration(3599)` === `"59:59"`
- `formatCompactDuration(3600)` === `"01:00:00"`
- `formatCompactDuration(3661)` === `"01:01:01"`
- `formatCompactDuration(86400)` === `"24:00:00"`

**页面验收标准：**
- 输入 `3661`，页面实时显示 `01:01:01`。
- 页面展示的 7 条验收示例全部标注为"通过"。
- 打开页面无需安装任何依赖或执行构建命令。

**范围限制：**
- 使用 JavaScript 模块实现，不使用 TypeScript。
- 不需要 DOM 之外的后端能力：无 HTTP API、数据库、Provider 调用或第三方依赖。
- 演示页面为独立静态页，无需接入现有业务页面。
- 需要为上述验收示例补充自动化单元测试。
- 不需要使用playwright等类似功能进行任何网页测试
