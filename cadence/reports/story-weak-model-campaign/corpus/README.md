# Story weak-model campaign corpus

Five frozen API-creatable Issue descriptions, one file per shape:

- `01-pending-confirmation.md`: an unresolved product decision that must invoke AskUserQuestion.
- `02-review-revision.md`: explicit boundary conditions intended to produce a reviewer must-fix if omitted.
- `03-user-choice-issue-0001.md`: extracted verbatim from issue_0001 canonical-inputs system message.
- `04-multiple-constraints.md`: scope and dependency constraints.
- `05-simple-pure-function.md`: a single pure function.

`digests.txt` is the freeze record. No campaign runner may rewrite corpus files.
