### 3.3 能走通的那条链（可复现步骤）

关键条件：**reviewer provider 不能写 `Fake`**。`src/product/workspace_engine/decisions.rs:254-267` 有「Fake 快速路径」——`if reviewer == ProviderName::Fake` 直接把评审节点标记 `skipped`（"未执行真实 review（Fake 快速路径）"）并跳到人工确认；此时 fixture 永远不会被消费。而 fake 模式下 `fake_mode_provider_registry`（`src/web/state.rs:541-566`）把 `claude_code`/`codex`/`pi`/`kimi_code` 全部映射到 `TestControlledFakeStreamingProvider`，且 fake 模式下 provider 可用性判定恒真（`src/web/state.rs:222-228`），因此：

2) POST /api/test/workspace-sessions/{sid}/review-fixture
   {"verdict":"needs_human","summary":"1a 自动化替身：驱动门开","comments":"needs_human fixture"}  → {"status":"ok"}

### 3.4 不可达项与根因（R1–R3，均为 1a 范围之外）

**R1｜计划指定的 `work_item_plan` 会话 + fake author 走不通（Legacy 流）**
`start_generation` 于 work_item_plan 会话触发 `work_item_plan_outline_run`（`src/web/workspace_ws_handler/decisions/inbound.rs:641-651`）。fake provider 的输出脚本只覆盖四类提示词（`src/cross_cutting/streaming_provider/fake.rs:167`「Work Item Splitter / IssueWorkItemPlan」、`:352` Design、`:373` Work Item Plan、`:396` Work Item），而 Outline Planner 提示词（`src/product/work_item_split_engine/prompts.rs:692-704`，「你是 Aria 的 WorkItemPlan Outline Planner」）**不在覆盖内**，落到兜底 Story Markdown 分支。实测帧：

```
{"type":"timeline_node_updated","node_id":"timeline_node_002","status":"completed",
 "summary":"WorkItemPlan Outline 结构化输出解析失败（errors: 1, warnings: 0）"}   # 自动重跑 #2 同上
{"type":"timeline_node_created","node":{"node_id":"timeline_node_004","node_type":"work_item_plan_context_blocker",
 "stage":"prepare_context","status":"active","summary":"Outline 结构化输出解析失败，请补充上下文…"}}
```
持久化结果：会话 `status = waiting_for_human`，**reviewer 从未运行 ⇒ fixture 未被消费 ⇒ 无门开**。

**R2｜`SingleCandidate` 流（`--work-item-plan-single-candidate`，与既有真实链进程同参数）同样走不通**
`flow_kind = SingleCandidate`（单仓 preflight 恒 Eligible，`src/web/handlers/lifecycle.rs:587-599`）→ 作者 run 为 `WorkItemPlanSingleCandidateAuthor`，其交付是进 compiler 的 Markdown 计划文档。
- 首次实测直接报错（缺仓库级规则文件）：
  `{"type":"error","message":"load required SingleCandidate language rules failed for repository /tmp/aria-t13-1a/workspace/.aria at /tmp/aria-t13-1a/workspace/.aria/.claude/rules/language.md: No such file or directory (os error 2)"}`
- 补齐该规则文件后重试：作者 run 进入 `running` 后**不再产生任何 provider 事件**（120s 内仅 `provider_locked` / `timeline_node_created` / `stage_change:running`），会话停 `running`，无门开。
- 结论：SC 流的 fake 替身能力同样不足以驱动门开；**不建议**在 1a 关闸上继续投入（属替身能力缺口，不是 1a 交付缺口）。
