## 3. Task 10 红灯发现并修复的真实缺陷（授权接缝内）

1. **`reopen_for_resume` 违反 Pending 形状不变量**
   （`aggregate_initialization_store.rs`）：Failed 步重置 Pending 时未清
   `input_digest/output_artifact_ref`，真实协调器产生的 Failed operation
   无法重开（A03 红灯定位）。修复后 A03 全链可达 planning_ready。
2. **identity repair handler 吞掉 submit_mapping 的 mapping**
   （`handlers/identity_repair.rs`）：`(_, Some(_))` 通配误吞 submit_mapping
   分支，SubmitMapping 在 HTTP 层完全不可用（A04 红灯定位）。修复分支次序。
3. **诊断契约缺 `journal_updated_at`**：GET repair 不暴露 journal
   `updated_at`，客户端无法构造合法 `expected_journal_updated_at`。补齐
   product/DTO 字段。
4. **生产 provider turn 驱动未接 admission**（授权缺口①）：生产依赖改经
   `claude_code_with_admission`，成员规则缺失时 provider 零启动（A04 证据）。
5. **bootstrap 投影 rules_policy 步不做成员规则只读检查**（授权缺口②）：
   缺失 → `waiting_for_human` + `member_rules_missing` + Prepare/Retry。
6. **member_index 显式 Retry 后无原链续跑**（授权缺口③）：bootstrap action
   handler 补 run-lease + `execute_remaining` + detached index build 接线。
