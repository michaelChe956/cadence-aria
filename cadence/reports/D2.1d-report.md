## 锁序与边界（plan §0.4/任务 Interfaces）

- 固定序 **scope → manager engine Mutex → arbitration → 对象锁**：准入只在入口（web 两入口/engine 独立包装）
  取得，engine/arbitration 锁内一律消费（`guard_round_admission` 纯读），无嵌套首次取 scope。
- 准入在持期间删除独占/工作区重置（H2a 闭包经 `try_acquire_delete(Plan)`）立即 Busy——跨进程
  reset/start 只有一个胜者；lease 持续整个 engine 操作（含 manager miss 裸 engine 路径）。
- 内层 D2.1c/D1.2c 各 store 写的 `with_plan_live_write` 为同 scope 共享重入（flock 多 FD 共享无冲突），
  迟到写防御保持；围栏读在准入共享区内，与生命周期写（持 Plan 独占）互斥。
- 不改：runtime graph/trust/coding opt-in、原幂等/CAS/预算/nonce、`map_advance_outcome` 语义、
  H1 error.rs 白名单（`coding_plan_workspace_clearing` 409 映射仍归 H1）；`advance_plan` 的 enrolled
  预检/身份链原语义零变化（准入插在 session 解析后、预检前，预检读全部仍在准入保护内）。
