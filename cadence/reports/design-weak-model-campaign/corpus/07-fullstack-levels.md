# 需求：naruto H5 游戏新增「关卡列表 API 与关卡选择页」

为 naruto H5 游戏（当前为空仓库骨架）设计一个「关卡列表」功能：后端提供关卡数据 API，前端提供关卡选择页面。请产出设计文档：定义后端服务的运行方式、API 契约（字段、错误语义）、静态页面托管方式、前端渲染与异常展示行为、前后端联调的验证方式。只做设计，不实现代码。

约束：

- 不引入任何 npm 依赖，后端只用 Node 内置模块（node:http、node:fs），前端为原生 HTML/JS。
- 测试只用 Node 内置测试运行器（node --test），不引入测试框架。
- 不新增数据库、认证、外部服务。
- 关卡数据为静态 JSON 数据文件，包含 5 个关卡，字段含 id、name、difficulty、unlocked。
- 前端在 API 失败时展示可读错误提示，不白屏。

考察点：全栈拆分形态——后端契约、前端消费、集成验证三段的边界与依赖关系。
