## 3. 角色层对照 ★（只比「走到第二轮评审」的 run，消除早死 run 的构成偏差）

> 改前 4 个 run 里只有 2 个走到第二轮评审（另 2 个在作者轮早死）；改后 4 个**全部**走到。直接比全样本会让「早死 run 只花很少 token」污染均值，故此处只取走到第二轮的 run。

| 维度 | 改前（n=2） | 改后（n=4） | 变化 |
|---|---|---|---|
| **评审参与率（走到第二轮）** | **2/4** | **4/4** | **50% → 100%** |
| **【author】耗时** | 1380s | **917s** | **−33.6%** |
| **【author】token in** | 107,927 | **79,582** | **−26.3%** |
| 【author】token out | 25,234 | 28,641 | +13.5% |
| 【author】产出 source 字节 | 14,830 | 15,388 | +3.8% |
| **【reviewer】耗时** | 261s | **135s** | **−48.3%** |
| 【reviewer】findings 总数 | 7 | 4 | −42.9% |
| **【reviewer】must_fix 数** | 4 | **2** | **−66.7%** |
| 【reviewer】suggestion 数 | 2 | 2 | 0 |
| **【reviewer】重复报** | 2 | **0** | **−100%** |
| **【reviewer】工具调用** | 24 | **11** | **−55.1%** |

⇒ **每个角色都更快、更省，且评审结论更干净**（must_fix −67%、重复报 −100%、工具调用 −55%），而产出字节反而略多（+3.8%）。

**机制解释**：
- **author**：拿到基线树事实（D5 事前）⇒ 不必靠工具往返猜仓库长什么样 ⇒ 工具调用与 input token 都降；第一轮就写出结构合法的 source ⇒ 走到第二轮评审的比例从 50% 升到 100%，「早死」消失。
- **reviewer**：前轮 findings 以「带本轮复算状态的分区事实清单」呈现（D6）⇒ 不再对已修好的项重复报 ⇒ must_fix 与重复报同时下降、工具调用减半（不用再翻上下文核对同一件事）。
- **preflight/compiler**：改前的 2 次拦截全部是 `intent_unexecutable`；改后出现了 `acceptance_path_not_in_baseline` 与 `write_scope_outside_bound_repository` ⇒ 越界**形态**变了（从「意图/写范围错」扩到「路径越界」）—— 提示 D5 事前让作者开始引用真实仓库路径（因而暴露新的路径类问题），这是**正面但未完成**的信号：多仓基线树只覆盖一个仓的既有缺陷仍在。

## 4. 结论

1. **D6 有效（有阳性对照）**：同时段下改前 2 个 run 出现第二轮重复报（重 1 条 / 重 2 条），改后 **0/4**；第二轮 must_fix 从 4 降到 2。⇒ 抱怨③「重驱后重复报错 → 自动化耗尽 → 人工介入」这条链被切断。
2. **D5 事前 + D6 组合使计划产出率从 0/4 升到 2/4、编译通过从 0/4 升到 2/4、未产出计划从 2/4 降到 0/4。**
3. **代价极小且全在正向量上**：总墙钟持平（1181 → 1180s）；作者更快（−34%）更省（in −26%）；评审更快（−48%）更干净；产出不缩水（+3.8%）。
4. **上一轮「+143% 变慢」是时段混杂，已撤回。**
5. **仍存在的坎（不属本次 change）**：① 多仓基线树只覆盖一个仓（校验器用它判所有仓的路径）⇒ 多仓计划的路径类越界无法根治；② `suggestion`+`class_hint=repairable` 被判必关闭 ⇒ 仍会升级人工。

---

## 5. 局限

1. **n=4/臂 ⇒ 比例型指标统计不显著**（Fisher 单尾 p = 0.214）。结论依据是「方向一致 + 机制可解释 + 与上一轮四臂实验的交叉一致（重复报 0/5 vs 3/4）」，不是统计显著性。
2. **单案例**（`公告删除`，三成员仓）、**单 provider 状态窗口**。
3. **D5 事前 / D5 事后 / D6 三者的独立贡献未分离**（本实验只切了「全体改前/改后」）；A/B 臂（关 D5 事前、留 D6）曾在上一轮跑过 n=4，但两臂并发有实验瑕疵，**不计入**。
4. 改后的 2 次人工介入归因不同（必关闭判定过宽 / 写范围越界），**未**逐一做归因实验。
