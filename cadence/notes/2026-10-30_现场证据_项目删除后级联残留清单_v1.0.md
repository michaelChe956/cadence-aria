## 关键事实

1. **attempt 本体已删**（`projects/project_0002` 与 coding attempt 本体记录都不在了），
   **但 attempt 的外围状态一个都没跟着删**。
2. **reviewer 窗口的 `identity` 指向已不存在的 worktree**（死路径）：
   ```
   /home/michaelche/workspace/test-folder/test-center-java/frontend/.worktrees/
     aria-issues/issue_0001/86ef47b8-289f-4119-bf88-d37bd907f071      ← 已从 git 注销且目录已删
   ```
   窗口仍持有该路径、`common_dir`、`gitdir` 与 `lease_id`（`wlease-coding_attempt_...-w01`）。
3. **这些残留不阻塞重新登记**：聚合根唯一性门禁枚举的是「manifest 优先，缺 manifest 回退
   `record.json`」（`src/product/logical_codebase/registration_preflight.inc.rs`
   的 `ensure_aggregate_root_unowned` / `existing_lc_roots` / `collect_project_lc_roots`），
   残留里**没有任何 manifest / record.json 指向该根** → 重新登记不会被 `aggregate_root_overlap` 拒。
   → 所以这是「**闭包不完整**」，不是「功能不可用」。
