### 1. `cas_internals.inc.rs`（2-A 判定放宽，`supersede_terminated_enrollment`）

改前（单判据）：

```rust
let options_or_target_drifted = &saved.options != options
    || saved.target.as_ref().is_some_and(|declared| *declared != *target);
let source_drifted = &saved.source != source;
if options_or_target_drifted || (source_drifted && !original_source_dangling) {

}
```

改后（按路径分流；两个半支各带 B1S3 片 3 的 `ConflictKind` 判别位）：

```rust
let options_drifted = &saved.options != options;
let target_drifted = saved.target.as_ref().is_some_and(|declared| *declared != *target);
let source_drifted = &saved.source != source;
// options 漂移仅在悬空源重授权路径构成拒绝条件（正常重开按换代放行）。
if options_drifted && original_source_dangling {
    return Ok(CasResolution::Conflict {
        current_revision: Some(saved.policy_revision),
        kind: ConflictKind::DefensiveStateMismatch,
    });
}
// target 漂移在两条路径上都构成拒绝条件；source 漂移仅在正常重开路径构成拒绝条件。
if target_drifted || (source_drifted && !original_source_dangling) {
    return Ok(CasResolution::Conflict {
        current_revision: Some(saved.policy_revision),
        kind: ConflictKind::SourceTargetDrift,
    });
}
```

**最终判定（供 controller 复核 H-1）**：
- **正常重开（`original_source_dangling == false`）：options 漂移 → 放行（不构成 Conflict；取代留痕承担改写可见性）；target 漂移 → 拒；source 漂移 → 拒。**
- **悬空源重授权（`original_source_dangling == true`）：options 漂移 → 拒（`DefensiveStateMismatch`，REQ-DRG-18 不变）；target 漂移 → 拒（`SourceTargetDrift`）；source 漂移 → 放行（既有语义不变）。**

整条 options 检查未删除（H-1 ✓）；未引入「options 不同才换代」判据（C-2 ✓——取代只认 `terminated_at.is_some()`，与 options 异同无关，测试 ③ 钉住）。

2-B 判据上方注释块同步改为按路径表述（见代码）；`:29-31` `bind_plan_ids_locked` 文档注释保持不变（本就与行为一致）。
