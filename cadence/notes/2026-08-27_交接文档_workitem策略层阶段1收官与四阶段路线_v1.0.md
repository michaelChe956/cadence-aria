## subagent 协作要点（本会话实测）

- 分工：scout 勘察 / oracle 决策推荐 / researcher 调研 / ter-worker 执行 / reviewer 审核

- **supervisor 提问**：通过 subagent_supervisor pending/reply 处理；progress update 不是阻塞提问
- **并行可行但要先消除共享文件竞争点**（如 mod.rs 注册 stub 先行）；cargo target 锁会让并行构建排队，可接受
- 子代理 bash 默认 cwd 可能落在主仓库而非 worktree——要求它们显式 cd
