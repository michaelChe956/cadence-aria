## 4. 日志里唯一一条指向 `/rustc` 的错误

**现象**：`/tmp/aria-full-lib-test.log` 全文只有一处出现 `/rustc/...` 位置（`:1850`）：

```
error[E0277]: the trait bound `Mutex<VecDeque<Result<BoundedCommandResult, _>>>: From<_>` is not satisfied
   --> src/web/handlers/provider_installation.rs:359:34
    |
359 |                 results: results.into(),
help: … but trait `From<std::collections::VecDeque<…>>` is implemented for it
   --> /rustc/58cf8f9c35b355199727627d07ae34a4e2846d67/library/std/src/sync/poison/mutex.rs:682:0
```

⇒ `/rustc/.../poison/mutex.rs:682` 只是 std 里 `impl From<VecDeque<T>> for Mutex<VecDeque<T>>` 的**位置标注**，**真正错误点在 `src/web/handlers/provider_installation.rs:359`**（`#[cfg(test)] mod tests` 内，321 行起）：

```rust
struct ScriptedRunner {
    results: Mutex<VecDeque<Result<BoundedCommandResult, BoundedCommandError>>>,
    …
}
…
Arc::new(Self { results: Mutex::new(results.into()), delay })   // results: Vec<…> ⇒ 类型不匹配
```

**修法**（零额外分配）：`Mutex::new(VecDeque::from(results))`
—— `VecDeque: From<Vec<T>>` 复用 `Vec` 的分配（无拷贝），`Mutex::new` 命中 std 的 `From<VecDeque>` impl（正是 help note 指的那条 impl）。

**同模块连带两处**：
