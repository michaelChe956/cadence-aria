## 操作流程(按顺序)

### 1. 建项目+LC+多仓登记

1. 打开 http://127.0.0.1:4317 → 首页会重定向到工作台
2. 新建项目(任意名)
3. 「添加代码库」→ 选「多仓库(逻辑代码库)」→ 起名
4. 登记向导会自动发现 /tmp 下的成员仓——**如果没有**,需要先在 /tmp 下准备几个 git 仓(方法见下方「准备测试仓」)

### 2. capability 核验(新功能)

1. 建好 LC 后,管理面板会出现 **「Provider 能力状态」卡**(四家×三行)
2. 状态全是「未核验」→ 点任一 provider 的 **「核验」按钮**
3. 首次点击会跑真探针(约 30 秒~几分钟),完成后显示「已核验」
4. 再次点击秒回(「已核验,无需重验」)——**这是一次性通道,不重复消耗**

### 3. 建多仓 Issue

1. 点「新建 Issue」→ 对话框打开
2. **成员列表变成了复选框**(不再是单选)——勾选多个成员仓
3. 填标题+描述 → 创建
4. 勾 1 个=单仓(与旧行为一致);勾 4 个=多仓

### 4. 走五阶段(story→design→plan→coding→review)

1. 从 Issue 详情区点「生成 Story Spec」→ 进入会话页
2. **首次会撞 capability 墙**(如果第 2 步没做核验)→ 回到 LC 管理面板点核验 → 重试
3. Story 生成完 → 回工作台,**阶段面板**切到 Story → 确认定稿(cockpit 页的「确认定稿」按钮)
4. 同样流程走 Design → Plan(多仓 plan:四仓 involved 可收敛到子集)→ Split(出多个 Work Item)→ Coding → Review
5. **issue 交付状态面板**(B1 修复):工作台详情区现在常驻显示

### 5. 多仓 Plan 特殊验证

- Design 确认后 → 生成 Work Item → 对话框选 Author/Review provider(四家可选)
- 多仓 plan 会话 WS 可建立(S6 修复:≥2 仓时回落聚合根视图)
- Plan 产出的 Work Item 会按仓分配 target
