## ③ 分诊按钮化：环境类失败挂「重新检测」（只改前端实现）

**文件**：`web/src/components/lifecycle/BootstrapFailureLine.tsx`（+ 同目录 `BootstrapFailureLine.test.tsx`）

### 复用的既有函数与字段（未新造）

| 用途 | 复用对象 | 位置 |
|---|---|---|
| 请求动作 | `recheckProviders()` → `POST /api/providers/recheck` | `web/src/api/client.ts:367-371`（**直接调用**，未新造 API、未包新 service） |
| 分诊判定 | `copy.triage` / `failure.triage`（`FailureCopyTriage`，三值 `environment` / `product_defect` / `retry_only`） | 后端 `failure_copy.rs` 五字段之一，经 `BootstrapFailureDto.copy` 下发 |
| 安装指引原文 | `ProviderHealthEntry.install_hint`（`web/src/api/types/provider.ts:21`），随 `/api/providers/recheck` 响应下发 | 后端 `src/web/handlers/providers.rs:35,83-114`（`provider_dto` 的 `install_hint`） |

**`install_hint` 字段前端拿得到 ⇒ 不需要上报缺口。** 该字段与 `recheckProviders()` 的返回类型 `ProviderHealthResponse` 同源（`providers[]` 每项含 `install_hint`），本次实现**逐字复用**该字段渲染安装指引，前端不自造安装文案。

### 按钮判定条件

`triage === "environment"`（即「环境问题（你这边可以修）」类）才渲染按钮。取值链：`copy?.triage ?? failure.triage`（与组件既有分诊标签**同源**，前端不另实现码表/describe——组件契约明确禁止）。`product_defect` / `retry_only` / 无 copy 的旧响应 ⇒ 不渲染按钮（后端文案已写明各自的下一步）。

### 进行中态与反馈

- **进行中态**：`disabled={rechecking}` + 按钮文案 `重新检测` → `正在重新检测`；另有 `useRef` 的 `inFlight` 闸门，保证同一时刻只发一次请求（重复点击不再发请求）。
- **成功反馈**：`重新检测完成：provider 全部可用，可点「重试」继续。` / `重新检测完成：仍有 N 个 provider 不可用（Codex、…），按下面的安装指引处理后点「重试」。` / `重新检测完成：本次未返回 provider 检测结果。`
- **失败反馈**：`重新检测失败：{错误信息}`（`Error.message` / 字符串 / 兜底「未知错误」），`role="alert"`。
- **安装指引**：不可用 provider 逐条列出 `{display_name}：{install_hint}`（`install_hint` 后端原文，逐字不改）。

### 样式（与邻近既有按钮一致）

- 按钮：复用**同一个「重新检测」动作**的既有实现 `web/src/components/providers/ProviderAvailabilityGuard.tsx:152-160` 的样式口径（`bg-[var(--aria-primary)]` + 白字 + `rounded-md` + `focus-visible:ring-2` + `disabled:opacity-50`），按失败面所在密度压到 `min-h-8` / `text-xs`。
- 文案：沿用本组件既有的 `text-xs leading-snug` + `text-[var(--aria-ink)]` / `text-[var(--aria-ink-muted)]` / `text-[var(--aria-danger)]` 口径（与同一张卡片里既有的琥珀色步骤动作按钮「重试」等**可区分**，不与它们混淆）。
- `data-testid`：`lc-bootstrap-failure-recheck` / `-recheck-feedback` / `-recheck-hints` / `-recheck-hint-{name}`，沿用本组件 `lc-bootstrap-failure-*` 命名族。
