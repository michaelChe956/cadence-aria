**精确位置**：`src/product/workspace_engine/review/routing_scope.rs:30-52` 的 `validate_single_candidate_scope`

**症状**：review 完成→verdict 处理→`work_item_policy_action`（routing.rs:164-168）从 cycle 计数推导 ReviewPhase→`single_candidate_policy_invocation` 读 durable scope→`validate_single_candidate_scope` mismatch→AbortFatal

**根因假说**（高置信度）：review 后的 phase 推导（从 cycle 计数）与 ensure 阶段的 phase 推导不一致——具体而言：
- ensure（provider 前）：cycle key 相同→counts 从 durable 读取→phase 判定

- 但 durable scope 已在 repair 路径中被升级为 Verification→mismatch

**修复方向**：
- 方案 A：review 后不验 scope（只在 ensure 阶段设置/验证），verdict 处理不依赖 scope phase
- 方案 B：policy 阶段的 phase 推导使用与 ensure 完全相同的 cycle key 逻辑（确保一致）
- 方案 C：返修/重试后确保 cycle key 不变或 scope 正确重置

**注意**：scopefix（dd9a0e3a）已修了「Verification scope 从 session.mechanical_report_ref 升级」——但 r22 codex 仍报同错，说明还有路径未覆盖。
