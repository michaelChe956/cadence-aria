## 2. 门卡分流后各错误族的 WS 字段形状（Plan 交付说明 ④ + 验收要求）

**WS 字段**：`SessionState.plan_continue_available: Option<bool>`（serde `default` + `skip_serializing_if = "Option::is_none"` ⇒ 旧客户端零变化）。

| 取值 | 服务端语义 | 前端消费 |
|---|---|---|
| `Some(true)` | 服务端此刻会为该会话提供底部「继续自动化」入口（与 HTTP `GET .../automation-enrollment/control` 的 `allowed_actions` 含 `continue_plan` **同源**，同一 `plan_control_facts` 派生） | `planContinueAvailable === true` ⇒ 分流表给出「指向底部输入框 +『继续自动化』」文案 |
| `Some(false)` | 服务端此刻**确定不会**提供该入口（enrollment 缺席 / 未启用 / 绑定不可用 / 已终止 / 停点不允许 continue） | 按「无真实续跑入口」处理（不指引去点「继续自动化」） |
| `None` | 服务端**未能判定**（会话记录或 enrollment 读取失败 / 非 work_item_plan 会话 / 未注入的旧帧） | 按「无真实续跑入口」处理（**不得给假指引**） |

**门卡分流表（durable `sessionStatus` 为主键）与其对应的 WS 字段形状**：

| durable 状态 | WS `plan_continue_available` | 门卡文案（`staleGateGuidance.copy`） | `action` | `showTerminate` |
|---|---|---|---|---|
| `confirmed` | 任意（该态不发「继续」入口 ⇒ 服务端给 `Some(false)`） | 「这一版已确认完成，此卡是历史记录，无需处理」（**逐字沿用 `GATE_STALE_COMPLETED_COPY`**） | `none` | `false` |
| `terminated` | `Some(false)`（terminated ⇒ allowed_actions 空） | 「这次自动化已经终止了，这张卡是历史记录，不用再处理。」 | `none` | `false` |
| `stopped_needs_human` + **`Some(true)`** | `Some(true)`（HTTP control `allowed_actions` 含 `continue_plan`） | 「自动化停在等你回话的地方，这张卡已经过期了。请在页面下方的输入框里写一两句说明，然后点『继续自动化』—— 它会带上你的说明接着跑，不用重新开始。」 | `continue` | `false` |
| `stopped_needs_human` + **`Some(false)`/`None`** | `Some(false)`（停点不允许）或 `None`（读失败/非 plan 会话） | 「自动化停下来了，但这张卡已经过期。自动化当前不接受新的输入，请刷新页面看最新状态，或到自动化控制面处理这一轮。」 | `none` | `false` |
| `failed` | `Some(true)`（SC 失败停点 `FailedProvider` ⇒ 含 `continue_plan`）/ `Some(false)`（非 SC 失败停点） | 「这一轮自动化跑失败了，这张卡已经过期了。请在页面下方点『继续自动化』重试；也可以先写一两句说明，一并带给 AI。」 | `continue` | `false` |
| 其余（推进到别的门：`open`/`running`/`waiting_for_human`/`change_requested`/未知） | `Some(false)`（无停点 ⇒ allowed_actions 空）/ `None` | 「会话已经走到下一阶段了，这张门卡不再接收操作。请以页面最新的一张门卡为准；如果这一轮确实要作废，可以点下面的『终止此门』。」 | `terminate_optional` | **`true`**（终止保留为**可选**出口） |
| **非过期卡**（`actionBlockReason === null`） | 任意（不消费） | 不在本表管辖 | `terminate_optional` | **`true`**（owner 正在用的「终止此门」按钮必须保留） |

**服务端谓词（`src/web/plan_stop.rs`）与 HTTP control 的同源关系**：`plan_control_facts()` 是**唯一**派生点——HTTP control handler 与 WS 投影都调它；`plan_continue_available` 的真值 = `facts.allowed_actions` 含 `continue_plan`（`facts.continue_available()`）。⇒ 两面**不可能**互相矛盾（5-C 的等价性由 Rust ⑮ 自动验证）。
