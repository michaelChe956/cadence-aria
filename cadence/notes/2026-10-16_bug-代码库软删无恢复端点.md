# Bug 报告: 代码库软删除无恢复端点,误删只能靠手工摘墓碑

- 报告人: 测试会话 (2026-10-16)
- 严重级: 产品缺口(数据安全)
- 现场状态: 已还原(owner 授权下手工摘除 tombstone.json,经 REST 验证 4 成员 active)

## 现象

owner 在页面误点 ttt 项目 notify-center 代码库的删除按钮,代码库即从列表消失。

## 还原过程(事实记录)

1. `DELETE /logical-codebases/{id}` → `delete_soft` 仅写 `logical-codebases/{lc_id}/tombstone.json`,record/manifest/members/checkouts/索引全部保留,成员仓零 git 副作用 —— 软删设计本身良好
2. `get_existing` 把 tombstoned 视为不存在;`create` 重建同名会生成**新 UUID 子树**,旧 id 关联(issue.json 引用 LC id、26 个文件引用成员 repo id)断裂
3. 全部路由中无 restore/undelete 端点;`identity-repair` 只修 git 身份
4. 最终在 owner 授权下删除 tombstone.json 单文件完成还原,GET codebases / LC 详情均恢复正常

## 建议

1. 提供 `POST /logical-codebases/{lc_id}/restore`(或 DELETE 幂等可逆):摘除 tombstone 前校验子树完整(record.json + manifest 存在)
2. 页面删除按钮加二次确认对话框(本次为误操作直达删除,无有效拦截)
3. 删除确认文案注明「软删除,可联系管理员恢复」或直接提供撤销入口

## 关键代码位置

- `src/web/handlers/codebases.rs:139` `delete_logical_codebase`(软删)
- `src/product/logical_codebase/store.rs:285` `delete_soft` / `:385` `get_existing`(tombstone 判定)
- `src/web/app.rs:107-111` 路由(无 restore)

## 症状 2(同日 14:03 后复现): 软删不释放身份注册表,重建登记被 already_registered 自锁

owner 在 test-java(project_0002)登记 test-center-java 三仓后误删该 LC,随后两次重建同名 LC 均无法登记成员仓,页面提示:

```
不可登记 /tmp/test-center-java/busi（already_registered）
不可登记 /tmp/test-center-java/frontend（already_registered）
不可登记 /tmp/test-center-java/gateway（already_registered）
```

### 根因

`delete_soft` 只写子树内 tombstone.json,不清理 project 级 `logical-codebase/identity-registry.json`:
三仓条目仍 `state:"active"` 并指向已墓碑 LC 的 logical_repository_id。
登记预检 `registration_coordinator.inc.rs:609` `IdentityRegistryStore::find_by_source` 命中 → already_registered,
导致「删了重建」路径也被堵死(比症状 1 更重:REST 重建这个官方替代路径不可用)。

### 现场还原(事实记录)

project_0002 下三个同名 LC: `446acaaf`(含 3 成员,被误删) / `2935e3db`(重建空壳,又删) / `4a600fd0`(重建空壳)。
处理: 摘 `446acaaf` 墓碑恢复原登记; `4a600fd0` 经 REST DELETE 删除; `2935e3db` 保持墓碑。
验证: codebases 列表仅剩 test-center-java(446acaaf),3 成员 active,manifest 完整。

### 建议补充

1. `delete_soft` 应同步释放 identity-registry 条目(state→released 或移除),或 `find_by_source` 跳过所属 LC 已墓碑的条目
2. tombstone 时若 LC 有成员,提示「重建同名后原仓无法登记」以止损
