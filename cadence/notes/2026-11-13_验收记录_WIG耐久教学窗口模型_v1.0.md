## ④ 「关闭某项即等价于只回退该项」对照结论（Global Constraints 第 19 行验收要求）

**依据两条用例的真实输出（见 ① 节定向复测段，均 1 passed / 0 failed）：**

1. **`denied_establishment_records_diagnostic_and_zero_extra`**（`cutover.rs:700`）——「教学重驱在批准闸门被关闭」的形态：播种非教学前缀条目使判据③拒绝（未批准 ⇒ `max_attempts=1, repair_once_approved=false`），首轮可教学失败（`missing_section`）后：
   - **零额外 provider 启动**（`no_more_provider_inputs` 钉死）；
   - 失败面**退回单轮现状形态**：`compile markdown source failed` + `missing_section` 真实原因回显，**不含** `after one teaching re-drive`；
   - phase=Failed；唯一新增物是**记账**而非调用——durable 诊断 `sc_teaching_window_not_approved` 同事务留痕 + 未批准窗口记录。
   ⇒ **判据不成立（关闭批准）时，可观测行为 == 把教学重驱整体回退后的现状失败面**，增量只有诊断与窗口记录（零模型调用、零额外启动）。

2. **`ab_balance_does_not_back_third_start`**（`cutover.rs:950`）——「窗口耗尽且预算面不受牵连」的形态：两轮 `missing_section` 耗尽窗口后：
   - **第三次启动 = 0**——且前提被钉死为 **A/B 两池余额充足**（fresh 记录 used=0/0、`max_repairs`/`max_manual_repairs` 均 > 0）：若实现把第三次启动落到 A/B 池兜底，余额并不构成阻碍 ⇒ 第三次为 0 **只能**由 C 窗口表达（`window.attempts.len()==2`、`Closed{Exhausted}`）；
   - 失败面按既有收口（`compile markdown source failed` + `after one teaching re-drive`）、phase=Failed。
   ⇒ **关闭（耗尽）C 通道不会把调用泄漏到 A/B 预算池**；反向亦然（Task 7 已证四数值记账面独立：①`repairs_used` ②`manual_repairs_used` ③窗口 attempts ④ledger 前缀过滤，任一停写恰使对应断言单独失败）。

**结论**：批准闸门关闭 ⇒ 行为等价于回退教学特性（零额外启动 + 现状失败面 + 仅记账增量）；通道耗尽 ⇒ 等价于只回退 C 通道（无跨账回补，A/B 池不受牵连）。两方向合并即满足「**关闭某项即等价于只回退该项**」——窗口只是记账收敛，未新增模型调用、未新增重试次数、未放宽写范围校验。
