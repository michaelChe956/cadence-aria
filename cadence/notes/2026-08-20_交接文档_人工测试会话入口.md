## 3. 当前模型（v1.3，测试时的正确心智）

```
Project
 └─ 代码库 × N（混合列表，kind 徽标：单仓/逻辑）
     ├─ 单仓代码库（原流程零变化）
     └─ 逻辑代码库 × N（零耦合，各含成员 × N）
issue 唯一归属一个代码库（单仓或逻辑）；逻辑专属操作全部按 lc_id 寻址
```

关键端点（新寻址）：
```
GET    /api/projects/{pid}/codebases
POST   /api/projects/{pid}/logical-codebases  body {name, aggregate_root}
POST/GET …/logical-codebases/{lc_id}/registrations[/preflight|{bid}|/resume|/cancel]
POST/GET …/logical-codebases/{lc_id}/initializations[/{oid}][+/cancel]
POST/GET …/logical-codebases/{lc_id}/aggregate-indexes[/rebuild|/active]
GET    …/logical-codebases/{lc_id}/members
…/logical-codebases/{lc_id}/pointer-publications[…]
（旧 /logical-codebase/... 端点=默认迁移 LC 兼容别名）
```
