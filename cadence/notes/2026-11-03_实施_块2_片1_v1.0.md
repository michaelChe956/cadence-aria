### 1.4 controller 批准的 Plan §2.2 偏离：审计预算失败把结构化载荷落进 `stderr_summary`

**批准人**：controller（Main）2026-11-03，**发现人**：片6（B2S6）。
**Plan §2.2 原文**：`Store(ProductStoreError::AuditSnapshotBudgetExceeded(_))` → `reason_code = aggregate_audit_budget_exceeded`、`cause = Some("audit_snapshot_budget_exceeded")`、`action` 留英文机器行、**`stderr_summary = None`**。

**偏离理由**：结构化载荷（`top_groups` / `member_summaries`）若不进记录，投影层只能回落到 `action`（= 机器码）⇒ 前端折叠区里只有一行机器码 ⇒ 片2 码表那句「**大项排行与成员仓见下方诊断**」的「下方」**永远落空** ⇒ REQ-AUD-04 要求用户能看到的预算明细拿不到。

**改前 → 改后**（`aggregate_initialization_coordinator.rs` 的 `error_record()`）：

```rust
// 改前
Self::Store(ProductStoreError::AuditSnapshotBudgetExceeded(_)) => (
    AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string(),
    false,
    AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string(),
    Some(AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string()),
    None,
    None,                      // ← stderr_summary：结构化载荷在这里被丢弃

// 改后
Self::Store(ProductStoreError::AuditSnapshotBudgetExceeded(failure)) => (
    AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string(),

    AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string(),
    Some(AUDIT_BUDGET_EXCEEDED_REASON_CODE.to_string()),
```
