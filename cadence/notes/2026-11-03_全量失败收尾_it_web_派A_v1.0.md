### 2.1 ws_handler×38（已实证，修法定型）

窄跑证据：
- `coding_ws_start_coding_pushes_engine_stage_and_timeline_events` → `coding_start_failed: product_store_io: target_snapshot_identity_drifted`（admission.rs:613，FailClosed 路由臂）
- `coding_ws_abort_attempt_closes_active_node_and_sends_snapshot` → `coding_abort_failed: product_store_not_found: issue issue_0001`（abort 完成读 issue，夹具无 issue 记录）

生产判定链（决定修法的关键事实）：
1. **admission**（admission.rs:589-618）：`(Logical, None)` → `target_snapshot_missing_for_logical`；`(FailClosed, _)` → `target_snapshot_identity_drifted`；`(Logical, Some)` → `validate_snapshot_fields` + policy digest 复验。⇒ **legacy None-快照 attempt 不可能过 StartCoding**，必须带与权威同源的冻结快照。
2. **launch**（lifecycle.rs:124-135 + launch.rs:52-100）：快照在场 ⇒ 经 `LogicalCodebaseProviderGateway` validated 启动 ⇒ `ProviderRef::from_provider_name(Fake)` fail-closed（provider_gateway.rs:467-476）⇒ 快照 attempt 的 provider 必须 ClaudeCode（或 Codex/Pi/Kimi）且 **替身需实现 `start_validated`**（trait 默认即拒绝，streaming_provider/mod.rs:1410）+ capability Confirmed + always-available gate。快照缺席 ⇒ 直连 `provider.start`（Fake 替身原样可用）。
3. **完成门**（gates.rs:125-137 `route_issue_shared_worktree`）：`None+Logical` 防御性 fail-closed ⇒ 即使 seed 成 Running 绕过 admission，完成链也会断。⇒ 快照是全链唯一形态。
4. **迁移器**（migration_executor*.inc.rs）：`ensure_identity_schema` 纯 JSON 落盘（record/manifest/member/checkout + issue selection/work item target 回填 + bootstrap policy），不触发 codegraph ⇒ **coding 链夹具无需 CODEGRAPH_FIXTURE_LOCK/rebuild**（issue_delivery_summary 先例同此）。
5. WebAppState 默认就带 `logical_gateway_factory`（state.rs:207）⇒ 快照 attempt 恒走 gateway，不可回避。
