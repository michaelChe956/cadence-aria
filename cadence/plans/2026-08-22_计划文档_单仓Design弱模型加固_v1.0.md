> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 单仓 Design 链路（issue → 已确认 Story → design 生成 → review → 用户反馈返修/choice 续写 → 确认）对弱模型可用，并以 baseline/revised campaign 提供与 story 同级的实测证据。

**Tech Stack:** Rust（workspace_engine/product 层）、Python3 stdlib（campaign 脚本）、cargo test（lib + it_core）、pnpm 不涉及（无 Web 改动）。

**Spec:** `openspec/changes/harden-single-repo-design-weak-models/`（proposal.md / design.md / specs/design-pipeline-weak-model-hardening/spec.md / specs/story-pipeline-weak-model-hardening/spec.md / tasks.md）
