# WIG 多成员基线树 实施计划 v1.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 plan 基线从「`issue.repo_id` 单仓平面路径集合」替换为覆盖**计划已授权全部有效成员**的共享结构 `PlanBaseline { member_prefixes, trees }`，并让加载、校验+最近候选、D5 渲染、结构摘要四端与全部调用方**一批**消费同一成员归属结构。

**Architecture:** loader 复用既有成员范围事实（manifest + active + selection，经 `plan_member_checkout_prefixes` 同一装载核心），逐成员按**自身 HEAD 分支**读 Git 树（`resolve_member_head_branch` 权威，不猜 main/master）；F3 路径域 = 聚合根相对成员前缀，裸仓内路径只兼容绑定本 WI 的 `target_repository_id`；归属不唯一 / 任一必需成员不可解析 ⇒ 显式 `Err`，不返回部分成功树；显示截断不缩小 validator 事实集合。rework 的 D5 装载点、装配与预算口径**不改**，只替换被装载的树结构。

**Tech Stack:** Rust（`std::process::Command` 调 git、serde、tempfile 既有 dev 依赖；零新增依赖）。

**Spec:** `openspec/changes/plan-baseline-multi-member/specs/per-issue-base-branch/spec.md`（MODIFIED REQ-PIB-01 / REQ-PIB-03）、`specs/work-item-plan-single-candidate/spec.md`（MODIFIED REQ-WSC-02）
