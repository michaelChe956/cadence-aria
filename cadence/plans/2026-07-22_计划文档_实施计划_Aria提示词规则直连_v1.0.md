# Aria 提示词原始规则直连 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Aria 各类新建或真实恢复的 Provider prompt 直接引用并遵守 Cadence-skills 的两份原始路由规则，同时不改变既有候选产物权限、人工 gate、Provider 恢复语义或结构化输出协议。

**Architecture:** 在 `product::cadence_skills` 增加一个无状态的原始规则路径引用片段；它只返回两份权威规则路径和“不得以摘要替代原规则”的说明，不保存节点状态、不映射生命周期、不伪造 Skill 执行记录。各现有 prompt builder 继续拥有自己的角色、阶段和输出合同，并在新建/真实恢复入口按当前阶段传入最小化路由说明；JSON、nonce sentinel、artifact fence 等纯格式修复入口保持隔离。

**Tech Stack:** Rust 2024、Cargo、现有 Provider prompt builder、OpenSpec、Superpowers、`cargo test --locked --lib`。

## Global Constraints

- **OpenSpec Change:** `standardize-aria-prompt-routing`；只能展开 `openspec/changes/standardize-aria-prompt-routing/` 中已确认的范围、设计和验收场景。
- **权威来源:** Provider 必须直接读取并遵守 `agent-routing-kernel.md` 与 `openspec-superpowers-workflow.md`；不得复制完整正文、另建 Aria 路由 DSL/枚举/状态机，也不得伪造已经调用 Skill 的记录。
- **规则路径:** 使用用户指定的 Cadence-skills 原始规则目录 `/home/michaelche/workspace/github/Cadence-skills/cadence-init/skills/rule-config/references/rules/`；不得把规则内容迁移到 `cadence/project-rules/`。
- **生命周期:** 新建任务和真实 Provider resume 重路由；仅 JSON、nonce sentinel、artifact fence 或已完成业务内容的结构化修复不得重路由，也不得要求新的首段路由回执。
- **当前阶段最小化:** 每个 prompt 只声明本节点阶段、紧邻前置条件和现有 Aria human-confirmation gate；不能注入完整生命周期或让 reviewer 再次 brainstorming。
- **既有合同:** 保留 `[openspec_contract]`、`[superpowers_contract]`、追踪关系、候选 artifact 权限、daemon canonical writeback、审批 gate、材料驱动协议、JSON/sentinel/artifact fence 和 Provider resume 行为。
- **严格机器输出:** 当现有节点要求“only JSON”时，保持最终 payload 不变；原生 Skill 路由/回执不得被塞入 JSON 字段，也不得破坏 sentinel 或 artifact 解析。允许可读前导的节点才可在最终 payload 前输出原规则要求的路由回执。
- **禁止依赖:** 不引入 `cadence-workflow`、Hook、插件或阅读状态机；所有新增 prompt 回归断言均验证不存在 `cadence-workflow`。
- **验证:** 先写失败测试，使用 `cargo test --locked --lib <过滤名>` 做定向反馈；不得给 Cargo 添加 `-j 1`。最终执行 `cargo fmt --check`、`cargo clippy --all-targets --all-features --locked -- -D warnings`、`cargo check --locked`、`cargo test --locked`。
