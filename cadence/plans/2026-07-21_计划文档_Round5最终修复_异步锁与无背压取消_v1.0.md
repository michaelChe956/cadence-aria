# Round 5 异步锁与无背压取消实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 本任务禁止委派子 Agent，步骤使用 checkbox 跟踪。

**Goal:** 修复 Group bind-before-phase 恢复、Tokio worker 上阻塞 flock、HTTP/WS Abort/Delete event backpressure 与跨 Store guard 误用。

**Architecture:** production runner registration 原子携带 `CancellationToken`，handler 先 cancel/wait 后执行 durable mutation；file guard 使用 `spawn_blocking` async acquire。Group replay只在严格磁盘 identity 校验后接受 `AttemptPersisted + owner=journal Attempt`。

**Tech Stack:** Rust 2024、Tokio、tokio-util CancellationToken、Axum、flock、Serde JSON store。

- [x] 实现：

```rust
pub(crate) async fn acquire_async(target_path: &Path) -> Result<Self, ProductStoreError> {
    let target_path = target_path.to_path_buf();
    tokio::task::spawn_blocking(move || Self::acquire(&target_path))
        .await
        .map_err(|error| ProductStoreError::Io(format!("join file lock acquisition: {error}")))?
}
```
