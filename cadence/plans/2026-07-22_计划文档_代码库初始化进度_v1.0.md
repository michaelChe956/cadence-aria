# 代码库初始化真实进度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将“添加代码库”改为可持久化、可轮询的五步真实初始化操作，并以无中断 Claude Code 命令驱动可访问的前端进度面板。

**Architecture:** 后端在完成 Project、Git 根目录及同路径互斥预检后，持久化一个 `repository_initialization` operation 并返回 `202 Accepted` 快照；后台 Tokio 任务持有初始化锁，严格按固定五步更新 operation 文件，最终写入 Repository 或结构化失败。前端在弹窗内轮询 operation 快照，完全以服务端步骤状态驱动 UI；仅在成功终态且返回 Repository 后刷新工作台列表。

**Tech Stack:** Rust 2024、Axum、Tokio、Serde/JSON 文件存储、React 19、TypeScript、Tailwind CSS、Lucide React、Vitest、Testing Library。

## Global Constraints

- Change：`add-repository-initialization-progress`；实施只能展开其已批准的 proposal、design、specs 和 tasks，不得扩大范围。
- 固定且唯一的用户可见步骤顺序为：`cadence_skills`、`rule_config`、`pre_check`、`mcp_configuration`、`project_rules_examples`。
- 步骤状态只能为 `pending`、`running`、`completed`、`failed`；后端是唯一事实来源，不得以计时器或百分比伪造进度。
- 四个 Claude Code 提示词必须逐字使用：`/rule-config --no-interrupt`、`/pre-check --no-interrupt`、`/mcp-configuration --no-interrupt`、`/project-rules-examples --no-interrupt`。
- 启动接口为 `POST /api/projects/{project_id}/repositories`，返回 `202 Accepted`；查询接口固定为 `GET /api/projects/{project_id}/repository-initializations/{operation_id}`。
- operation 文件保存于 `<ProductAppPaths>/projects/{project_id}/repository-initializations/{operation_id}.json`；最终 Repository 仍只保存到现有 `repos.json`。
- 初始化中不可关闭或取消；不实现 SSE、WebSocket、日志流、步骤内进度、后台取消或旧 operation 原地重试。
- 不新增 Cargo、pnpm 或其他第三方依赖；使用已有 `uuid`、`lucide-react`、JSON store 与 CSS 变量。
- operation 对外 DTO 不得泄露本机绝对路径、Cadence source/skills 路径或未脱敏错误；沿用 `repository_registration_response` 的脱敏规则。
- 不触碰 KnowledgeBase 或 `cadence-workflow` 内容。
- 所有代码、测试与用户可见文案使用中文；实现遵循 TDD。Rust 命令禁止带 `-j 1`。

```rust
#[derive(Clone, Default)]
pub struct RepositoryInitializationRunRegistry {
    active: Arc<StdMutex<HashSet<String>>>,
}

pub struct RepositoryInitializationRunLease {
    registry: RepositoryInitializationRunRegistry,
    operation_id: String,
}

impl RepositoryInitializationRunRegistry {
    pub fn register(&self, operation_id: String) -> Option<RepositoryInitializationRunLease> {
        let mut active = self.active.lock().expect("repository initialization run lock");
        if !active.insert(operation_id.clone()) {
            return None;
        }
        Some(RepositoryInitializationRunLease {
            registry: self.clone(),
            operation_id,
        })
    }

    pub fn is_active(&self, operation_id: &str) -> bool {
        self.active
            .lock()
            .expect("repository initialization run lock")
            .contains(operation_id)
    }
}

impl Drop for RepositoryInitializationRunLease {
    fn drop(&mut self) {
        self.registry
            .active
            .lock()
            .expect("repository initialization run lock")
            .remove(&self.operation_id);
    }
}
```
