## 0. 全局约束（违反即返工）

1. **不动已落地的失败面工作。** `web/src/components/lifecycle/AggregateIndexCard.tsx` 的三段失败面/证据面渲染、`web/src/components/lifecycle/AggregateIndexCard.test.tsx` 的既有 10 个用例、`src/web/handlers/aggregate_index.rs` 的 `failure_copy`/`evidence_copy` 互斥，一律**保持语义不变**；本计划只在旁边加跳过行与成员标注。
2. **判定点唯一。** 四态判定只写在 `AggregateIndexAcceptance::verify`；UI、投影层、`freshness.rs` 都**不得**复算「有没有源码」。`freshness` 只负责「要不要重新验收」。
3. **无法确认 ≠ 无源码。** 盘检因权限/IO/超时/超限未完成且无正证据时必须 `Unknown`（失败），任何代码路径不得把它降级成 `NoSource`。
4. **`included` 语义冻结。** `AggregateIndexMemberSnapshot.included`（`aggregate_index/types.rs:24`）保持既有原义；跳过只由新字段 `skip_reason` 表达。`included` 还被 `planning_context_resolver.rs:621` 当 `available` 使用（design D4），写 `false` 会把跳过成员变成不可用目标仓。
5. **不加 `schema_version`、不写迁移。** 兼容只靠 serde 缺省：新字段必须 `#[serde(default, skip_serializing_if = "Option::is_none")]`；老 JSON 无字段即 `None`；`None` 不得被投影成跳过证据。
6. **不扩大 CodeGraph 收录范围。** 不改 `codegraph.json` 的 `exclude` 生成口径（`aggregate_index/exclude.rs:49-105`）、不生成 `extensions`、不改版本区间（`codegraph_cli.rs:22-23`，现行 `>=1.6.0, <2.0.0`）、不要求把配置/文档纳入索引。
7. **不新增后台轮询 / 不新增服务端点。** 创建 Issue、勾选成员、刷新页面、同一次生成中的后续对话都不触发索引刷新；三个入口共用既有组件 `web/src/components/lifecycle/LogicalCodebaseLayoutTree.tsx`。
8. **中文文案单一来源。** 用户可见中文全部来自 `src/product/logical_codebase/failure_copy_table.inc.rs` 的码表；前端**只渲染服务端下发的成品文本**，不得在 TSX 里写第二份同义中文（`LogicalCodebaseLayoutTree.test.tsx` 已有反重复文案守卫用例）。
9. **测试产物只落 `/tmp`**（`cadence/project-rules/test-content-tmp-only.md`）。夹具仓、`CARGO_TARGET_DIR`、日志、快照全部 `/tmp`；`cadence/reports/` 下的正式截图是交付证据，不算测试临时物。
10. **提交纪律。** 每片一次或多次提交，**显式列文件**；禁止 `git add -A` / `git add .` / `commit -a`；禁止在 `main` 上提交；禁止 `--no-verify`。可单独 revert 的粒度以 §1.1 的片为单位。
11. **不越界的只读边界**：不改 `openspec/`、不改 `cadence/designs/`、不重跑用户现场、不调用真实 provider（页面验收的 UA-12 除外，见 §16）。
12. **机械上限（每片）**：读文件 ≤6 次、`grep` ≤8 次；超出即说明该片该拆，回去按 §1.1 拆法处理，不要硬做。

| 情况 | 返回值 |
|---|---|
| 普通路径（根深度 0）内找到任一 Aria 源码后缀普通文件 | `SourceInNormalPath`（立即停止，不再扫 `.worktrees/`） |

**实现要点（不得偏离）**

- **后缀匹配**：取最后一个扩展名，`to_ascii_lowercase` 后与 `ARIA_SOURCE_EXTENSIONS` 比对；`archive.tar.gz` 只看 `gz`。
- **排除口径复用**：从 `super::exclude::BUILTIN_EXCLUDES`（`exclude.rs:16-31`，11 条）派生剪枝目录名集合——取以 `/` 结尾的条目，去掉 `**/` 前缀与结尾 `/`，得 `{.worktrees, .aria, .git, build, target, node_modules, dist}`；**不得**在 `source_scan.rs` 里再抄一份字面量数组。
- **两段扫描**：第一段 `member_root`，剪枝含 `.worktrees`；仅当第一段「完成且无源码」时，第二段以 `member_root.join(".worktrees")` 为根，剪枝同上（`.worktrees` 根自身不算剪枝）。
- **符号链接与非普通文件**：每个条目用 `std::fs::symlink_metadata`；`file_type().is_symlink()` 一律跳过（目录与文件都跳过）；只有 `is_dir()` 递归、`is_file()` 判后缀；其它类型跳过。
- **有界性**：每个目录条目（目录或文件）扣 1；`remaining_entries == 0`、`Instant::now() > deadline`、`cancelled` 三者任一 ⇒ 停止并（在无正证据时）返回 `Unknown`。
- **不模拟 `.gitignore`**：不做任何 ignore 解析（普通路径有源码但被 ignore 仍是真漏收）。
- **不启子进程**：不调 git、不调 CodeGraph、不读文件内容。

## 18. 风险与回退

### 18.1 回退粒度

- 每片至少 1 个 commit、显式列文件 ⇒ **每片可单独 `git revert`**（片11 甚至只 revert 一个文案文件）。
- **必须成组交付的片**（中间态不可上线）：
  - **片2 + 片3**：只落 `skip_reason` 字段而无人写，是**安全**中间态（字段恒 `None`，投影无告警）；但**禁止**出现「用 `included=false` 表达跳过」的中间态——本计划明令 `included` 不变（§0 约束 4）。
  - **片3 + 片4**：片3 会产出三个新码；没有片4 时它们落中性中文兜底（可用但不符合 REQ-BOOT-10/LAYOUT-05）。二者**同一 PR 合并**。
  - **片4 + 片5/6/8**：后三者 `use` 片4 新增的渲染函数，**编译级强依赖**，天然成组。
  - **片5 + 片9**、**片6 + 片10**：后端字段先行是安全中间态（前端忽略未知字段），但**上线应成组**，否则用户看不到提示。
  - **片7 单独**可交付（失败停机是收紧语义，不依赖其它片），但若片3 未落，重新验收仍会因覆盖失败而失败（不是错误行为，只是配置仓场景不可用）。
- **片12/片13 最后**：集成与页面验收不产生产品语义，可随任一 commit 之后追加。

### 18.2 版本与范围护栏

- **CodeGraph 版本区间不变**：`codegraph_cli.rs:22-23` 的 `(1,6,0)` / `(2,0,0)` 不得改；片0 探针若在某版本上失败，记录为「该版本未验证」，**不得**改区间去凑。

- **不加轮询/端点**：不新增后台定时任务、不新增只读接口、不新增服务；三个入口只改共用组件的文案。
- **不改 `included` 语义**：`planning_context_resolver.rs:621` 的 `available` 依赖它。

## 21. 实施者须知（每片开工前读一遍）

5. **每片 ≤3 个文件（含测试文件）**：超了就是该拆片，回去按 §1.1 的拆法处理；**不得**把两个片的改动塞进一次提交。
6. **机械上限**：每片读文件 ≤6 次、`grep` ≤8 次；先看 `ast-grep outline` 结构化大纲再定向精读（`.claude/rules/code-reading.md`）。
7. **提交**：显式 `git add <文件…>`；禁止 `git add -A` / `git add .` / `git commit -a`；禁止 `--no-verify`；**不得在 `main` 上提交**（`cadence/project-rules/branch-protection.md`）。当前分支 `feat/aggregate-index-failure-face`。
8. **命令注意**：
   - Rust 定向单测必须带 `--lib`：`cargo test --locked --lib <过滤名>`；集成用 `cargo test --locked --test <name>`；**禁止** `-j 1`。
