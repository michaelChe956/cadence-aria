> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 compile 阶段（generate 段）的失败从「模型读原始 message 自纠」改为「平台产出 typed 事实 → 确定性资格判定 → 教学重驱」：lowering 诊断携带独立 typed fault、四类 IR 诊断携带 typed 载荷、教学资格由码白名单改为 typed 完备判据（MODIFIED REQ-WSC-09）、Plan Intent 分支等价解析、Final Compile 环失败透传 Structure、内容 autorepair 按 O1 裁决迁原授权 author、prompt 固定教学块按计量闸门瘦身（15.5K → ≤8K）。
