# monaco 编辑器本地化（消除 CDN 依赖）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 monaco 编辑器从「运行时由 `cdn.jsdelivr.net` 动态加载」改为「本地打包 + `loader.config({ monaco })`」，让产物审核区在**无外网/内网环境**下也能正常渲染（markdown/json 高亮、代码 diff 双栏、编辑器 UI 能力全在），同时用契约测试锁死「不再走 CDN」这条不变量。

**Architecture:** 新增一个**副作用模块** `web/src/components/shared/monaco-local-setup.ts`：它 `import * as monaco from "monaco-editor"`（本地包）、用 Vite 的 `?worker` 说明符引入 5 个本地 worker、把 `window.MonacoEnvironment.getWorker` 按 label 分发到对应 worker，最后调用 `loader.config({ monaco })` 让 `@monaco-editor/react` 不再去 CDN 取 `paths.vs`。该模块由 `MonacoViewer.tsx` 与 `MonacoDiffViewer.tsx` 在**文件顶部**静态 import（`4ca055b7` 落在第 2 行，位于 `lazy(...)` 之前）⇒ 装配必然早于 `lazy(() => import("@monaco-editor/react"))` 的动态加载执行（`@monaco-editor/react` 的 `loader.init()` 见到 `config.monaco` 已存在即不再走 CDN）。Rust 侧**零改动**；唯一必须补的类型是 `web/tsconfig.json` 的 `"types": ["vite/client"]`（`?worker` 说明符的类型声明来源，缺了报 TS2307）。

**Tech Stack:** React 19 + TypeScript 5.7 + Vite 6（`?worker` import）+ Vitest 2（jsdom）+ `monaco-editor@0.55.1` + `@monaco-editor/react@4.7.0`（两者**已在** `web/package.json` 里，不新增依赖）；Rust 2024（`rust-embed` 的 `debug-embed` 把 `web/dist` 烤进二进制）；内置浏览器（`browser` 全局对象）做发布态验收。

**Spec:** `cadence/designs/2026-11-07_技术方案_monaco本地化_消除CDN依赖_v1.0.md`（权威技术方案，已定稿、owner 已批准）+ `openspec/changes/monaco-local-bundling/`（OpenSpec change：`proposal.md` + `tasks.md` + `specs/monaco-local-bundling/spec.md`；★该 change 与本 Plan 并发落盘，落盘后须与设计文档逐条校对一致★）。本 Plan 从该 spec 展开，契约与证据随文档一起走，实施者必须同时读设计文档与 change。

## Global Constraints

- **C1 前端 bundle 烤进二进制**：`Cargo.toml`：`rust-embed = { version = "8", features = ["debug-embed"] }` ⇒ **debug 也嵌入** ⇒ `web/dist` 涨多少，二进制就涨多少（release 另加 `strip`/`lto`/`opt-level=s`）。
- **C2 `?worker` import 需要类型**：`web/tsconfig.json` 未引 `vite/client` ⇒ `import ... from "monaco-editor/esm/vs/editor/editor.worker?worker"` 报 TS2307 ⇒ **必须**加 `"types": ["vite/client"]`（**任何方案都要**）。
- **C3 monaco 的 ESM 无聚合入口**：`esm/vs/basic-languages/` 只有 `_.contribution.js`（工具）+ 81 个语言目录，**没有** `monaco.contribution.js` 聚合入口 ⇒ 裁剪路线必须自己枚举 ⇒ 见设计文档 §4。
- **C4 用户下载 ≠ 二进制体积**：worker 与语言 chunk **按需加载** ⇒ 二进制增量不等于用户下载增量（实测 gzip 差 **25.7 kB**，见下）。
- **代价（诚实记录，设计文档 §5 逐字）**：**二进制 +13.6 MB**（`web/dist` 1.43 MB → **15.04 MB**；227.8 MB → ~241 MB debug；release 同比例）；**用户首屏下载（gzip）+25.7 kB**（主 chunk 1,338 → 1,364 kB ⇒ **几乎不变**）；**按需 chunk** worker/语言共 9.4 MB 进 `dist`（⇒ 进二进制）⇒ **只在实际用到该语言/服务时才下载** ⇒ 只读展示场景**永不加载**；**加载体验**变**快**（本地同源，无外网往返）；**构建时间** `pnpm build` **3 s → ~15 s**。
- **诚实边界 ①（json 运行时高亮）**：产物已含 `json.worker` + `jsonMode`，但**分词未实测** ⇒ 本轮**必须实测**「json 高亮运行时生效」，**不得假设**。
- **诚实边界 ②（worker 是否真起得来）**：`getWorker` 的 **label 分发未实测** ⇒ 本轮**必须实测**「各 worker 真的起得来」，**不得假设**。
- **诚实边界 ③（必须在发布态复验）**：本设计**未**验证各语言高亮在**生产构建**（非 dev）下的表现 —— spike 是在 **vite dev server** 上验的 ⇒ 实施时须在 **4317 发布态**复验。

## Review Focus

1. **加一行副作用 import 会炸既有单测**：既有 `web/src/components/shared/__tests__/MonacoViewer.test.tsx` 与 `MonacoDiffViewer.test.tsx` 都用 `vi.mock("@monaco-editor/react", () => ({ Editor: … }))` **整体替换**了该模块，**mock 里没有 `loader`** ⇒ 一旦 `MonacoViewer.tsx` 顶部加上 `import "./monaco-local-setup";`，这两个文件就会执行 `loader.config({ monaco })` ⇒ `TypeError: Cannot read properties of undefined (reading 'config')` ⇒ 既有 8 个用例全红。**合理的人会期望**：加一行装配 import **不炸既有单测**（Task 1 Step 3 必须同时给这两个既有测试文件各追加一行 `vi.mock("../monaco-local-setup", () => ({}));`，既有断言一条不动）。
2. **jsdom 里没有 `Worker` 全局** ⇒ 单元测试中一旦 `new JsonWorker()` 就会抛 `ReferenceError: Worker is not defined`（Vite 的 `?worker` 产物在构造时才 `new Worker(...)`）。**合理的人会期望**：契约测试只断言「装配行为」（`loader.config` 的入参 + `window.MonacoEnvironment` 已装上），**不假装验过 worker 构造**；「worker 真起得来」由浏览器实测承担（Task 4 Step 5），而不是在 jsdom 里硬凑。
3. **`"types": ["vite/client"]` 会关掉 `@types/*` 的自动全局包含**：`web/tsconfig.json` 原本**没有** `types` 字段 ⇒ 所有 `node_modules/@types/*` 都被自动全局包含；加了 `types` 数组后只保留数组里列的包 ⇒ 可能让依赖全局类型声明的文件（`@types/react` 的全局 JSX 声明等）冒出新错。**合理的人会期望**：加了 `types` 之后 `pnpm tsc -b` 仍然 **exit 0 且没有新增报错**；若确有缺失，只允许把**具体缺失的类型包名**追加进同一个数组（例如 `"types": ["vite/client", "…"]`），**不得**整体回退删除该字段。
4. **worker 路径随 monaco 版本变**：`monaco-editor/esm/vs/language/json/json.worker.js` 等路径是**版本相关**的 ⇒ 升级 monaco 后这些文件可能改名/移动 ⇒ 运行时会**静默**丢失语言服务（不报 404，但 json 高亮/校验失效）。**合理的人会期望**：升级 monaco 时同步 `monaco-local-setup.ts` 的 worker 路径，并**重跑验收判据 1~4**（Global Constraints 诚实边界 ④）。
5. **4317 是 `web/dist` 的编译期快照**：`rust-embed` 在 `cargo build` 那一刻烤进 `web/dist` ⇒ 只重建二进制不重建 dist（或反之）⇒ 线上跑的还是旧 UI ⇒ 此时「0 个 `cdn.jsdelivr.net` 请求」的结论会建立在**旧件**上而失真。**合理的人会期望**：`pnpm build` → `cargo build --locked` → 重启 4317 **三步齐做且顺序不可颠倒**，并用「线上页 JS 名 == 本轮 `web/dist`」自检（Task 3 Step 5 的指纹自检第 7 条）。
