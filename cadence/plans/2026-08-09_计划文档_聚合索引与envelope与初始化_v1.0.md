# 聚合索引、envelope 安全门与聚合初始化 Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 建立聚合 CodeGraph 索引、SessionPolicyEnvelope 安全门、聚合初始化 5 步，让逻辑代码库能建索引、安全启动 provider、跑聚合初始化。

**Architecture:** Cadence 在非 Git 聚合根维护 `codegraph.json` 的 `exclude` denylist，并把一份可审计、可恢复的 CodeGraph 索引记录写入 logical-codebase 权威存储。`LogicalCodebaseProviderGateway` 是逻辑代码库真实 provider 的唯一建造与启动入口，在 adapter 之前冻结并校验 envelope。`AggregateInitializationOperation` 独立于既有单仓六步 operation，以五个稳定 step ID 推进；其 coordinator 的依赖图不含 `RepositoryStore::create_repository` 或 GitFinalize。

**Tech Stack:** Rust, tokio, serde, uuid, codegraph CLI。

## Global Constraints

- 禁止 `cargo test -j 1`，也禁止给任何 Cargo 命令显式传入 `-j 1`；并行度由 `.cargo/config.toml` 管理。
- 定向单测必须使用 `cargo test --locked --lib <测试名>`，不得省略 `--lib`。
- CodeGraph 的可执行文件与 npm 包精确钉定为 `@colbymchenry/codegraph@1.5.0`；不得使用浮动 `latest`、`^1.5.0` 或 v1.4.1（规避 #1295）。
- 索引范围由 Cadence 生成的聚合根 `codegraph.json` 的 `exclude` denylist 决定。CLI 没有 allowlist；不得假定 CodeGraph 会按 Git 边界、manifest、`.worktrees` 或 `.aria` 自动隔离。
- envelope 是逻辑代码库 provider 从首次真实启动起就生效的门。`machine_skills` 与 `aggregate_preflight` 可以先行，`pre_check`、`rule_and_mcp_config`、`openspec_and_examples` 必须等 gateway 就绪后才可运行。
- 50 仓首次索引目标不超过 10 秒，超过 30 秒产生软告警，超过 120 秒失败或转异步；3–5 文件增量 sync 目标不超过 3 秒，超过 10 秒告警，超过 30 秒失败。spike 4 的 50 仓实测首次为 1.36 秒。
- inventory 注入默认不超过 4 KiB / 约 1,400 token，硬上限 8 KiB / 约 2,700 token；超限时只注入目标成员、计数和摘要，并通过索引查询补充。
- 稳定 ID 使用 UUID；禁止 `len + 1`、文件数、`repo_hash` 或路径哈希分配身份。任何 ID 组成磁盘路径前必须通过 `validate_relative_id` 或 UUID parse。
- 路由级 fail-closed 仅表示 Cadence 拒绝不受支持的启动；它不等价于端到端 OS 级文件隔离。能力保持 experimental + supervised，文档和 UI 均不得宣称物理不可写。
- 所有正文、测试名说明和错误 action 使用中文；Rust 标识符、JSON 字段、命令与 Conventional Commit message 使用英文。
- 本计划不改变单仓 `RepositoryInitializationOperation` 的六项 `ALL` 布局、旧 JSON/DTO 字节表示、传统 `RepositoryRegistrationCoordinator` 的 GitFinalize 行为；不实现成员最小指针发布、跨仓 coding 编排或 OS 沙箱。

```rust
// src/product/logical_codebase/aggregate_index/codegraph_cli.rs
pub const CODEGRAPH_EXACT_VERSION: &str = "1.5.0";

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum AggregateIndexError {
    Degraded { code: &'static str, message: String },
    Failed { code: &'static str, message: String },
}

pub struct CodeGraphCli { runner: Arc<dyn BoundedCommandRunner>, executable: String }

impl CodeGraphCli {
    pub fn verify_v1_5_0(&self) -> Result<(), AggregateIndexError> {
        let output = self.run(&["--version"], Path::new("."), 30)?;
        let actual = output.stdout.trim();
        if actual == CODEGRAPH_EXACT_VERSION { Ok(()) } else {
            Err(AggregateIndexError::Degraded { code: "codegraph_version_mismatch", message: format!("expected {CODEGRAPH_EXACT_VERSION}, got {actual}") })
        }
    }

    pub fn init(&self, root: &Path) -> Result<CodeGraphCommandResult, AggregateIndexError> {
        self.run_checked(&["init", "."], root, AggregateIndexBudget::FIFTY_MEMBER_INITIAL)
    }

    pub fn sync(&self, root: &Path) -> Result<CodeGraphCommandResult, AggregateIndexError> {
        self.run_checked(&["sync", "."], root, AggregateIndexBudget::INCREMENTAL)
    }

    pub fn files(&self, root: &Path) -> Result<Vec<PathBuf>, AggregateIndexError> {
        let output = self.run(&["files"], root, 30)?;
        Ok(output.stdout.lines().filter(|line| !line.trim().is_empty()).map(PathBuf::from).collect())
    }
}
```

`run_checked` 必须通过既有 bounded runner 传入 cwd、`fail_secs` 硬超时和被清理的环境；`--version`、`init .`、`sync .`、`query <symbol> --json`、`status .` 的 argv 在单元测试逐项断言。找不到二进制、超时、退出码失败和不可解析 JSON 均转换为带 machine-readable `code` 的 `AggregateIndexError`，以便 Task 7 保留 last-known-good。

```rust
// src/product/logical_codebase/aggregate_index/exclude.rs
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct CodeGraphConfig { pub exclude: Vec<String> }

pub struct CodeGraphExcludeGenerator;

impl CodeGraphExcludeGenerator {
    pub fn from_member_roots(root: &Path, member_names: &[&str]) -> Result<CodeGraphConfig, AggregateIndexError> {
        let allowed = member_names.iter().copied().collect::<BTreeSet<_>>();
        let mut exclude = Vec::new();
        for entry in std::fs::read_dir(root).map_err(io_error)? {
            let entry = entry.map_err(io_error)?;
            let name = entry.file_name().to_string_lossy().to_string();
            if !allowed.contains(name.as_str()) && name != "codegraph.json" && name != ".codegraph" {
                exclude.push(format!("{name}/"));
            }
        }
        exclude.extend([
            "**/.worktrees/", "**/.aria/", "**/.git/", "**/build/", "**/target/",
            "**/node_modules/", "**/dist/", "**/.env", "**/.env.*", "**/*credential*",
            "**/*secret*",
        ].into_iter().map(str::to_string));
        exclude.sort();
        exclude.dedup();
        Ok(CodeGraphConfig { exclude })
    }

    pub fn write_atomically(root: &Path, config: &CodeGraphConfig) -> Result<String, AggregateIndexError> {
        let encoded = serde_json::to_vec_pretty(config).map_err(json_error)?;
        atomic_write(root.join("codegraph.json"), &encoded).map_err(io_error)?;
        Ok(format!("sha256:{:x}", Sha256::digest(encoded)))
    }
}
```

生成器必须先验证每个 member main checkout 是聚合根的直接子目录、无重复相对名称、没有 symlink 逃逸；若 manifest 无法投影为此目录布局，返回 `aggregate_index_layout_unsupported` 而不是把未列成员视作安全。`atomic_write` 使用同目录临时文件、`sync_all` 和 rename；不覆盖 `.codegraph` 数据库，也不依赖成员仓 `.gitignore`。

```rust
// src/product/logical_codebase/aggregate_index/store.rs
impl AggregateIndexStore {
    pub fn replace_active(&self, project_id: &str, next: AggregateIndexRecord) -> Result<AggregateIndexRecord, AggregateIndexError> {
        validate_relative_id(project_id).map_err(store_error)?;
        let current = self.active(project_id)?;
        if let Some(mut previous) = current {
            previous.status = AggregateIndexStatus::Superseded;
            previous.updated_at = Utc::now().to_rfc3339();
            self.save(&previous)?;
        }
        self.save(&next)?;

    }
}

pub fn build(&self, project_id: &str, expected_membership_revision: u64) -> Result<AggregateIndexRecord, AggregateIndexError> {
    let manifest = self.logical.load_manifest(project_id)?.ok_or_else(|| missing_manifest(project_id))?;

    let config = self.excludes.generate(&manifest, &self.logical.list_members(project_id)?, &self.logical.list_checkouts(project_id)?)?;
    let config_digest = self.excludes.write_atomically(&manifest.provider_context_root, &config)?;
    self.cli.init(&manifest.provider_context_root)?;
    let acceptance = self.acceptance.verify(&manifest.provider_context_root, &snapshots)?;
    let mut record = AggregateIndexRecord::building(new_index_id(), project_id.into(), manifest.membership_revision, snapshots, Utc::now().to_rfc3339());
    record.status = AggregateIndexStatus::Active;
    record.codegraph_root = manifest.provider_context_root;
    record.warning = acceptance.soft_warning();
    record.updated_at = Utc::now().to_rfc3339();
    self.store.replace_active(project_id, record)
}
```

```rust
impl AggregateIndexSnapshotCollector {
    pub fn current(&self, checkout: &RepositoryCheckoutRecord) -> Result<AggregateIndexMemberSnapshot, AggregateIndexError> {
        if checkout.kind != CheckoutKind::Main || checkout.availability != CheckoutAvailability::Available {
            return Err(AggregateIndexError::Failed { code: "aggregate_index_checkout_unavailable", message: checkout.canonical_path.display().to_string() });

        let revision = self.git(&checkout.canonical_path, &["rev-parse", "HEAD"])?;
        let status = self.git(&checkout.canonical_path, &["status", "--porcelain=v1"])?;

        Ok(AggregateIndexMemberSnapshot::indexed(
            checkout.logical_repository_id, checkout.checkout_id, revision,
            !status.trim().is_empty(), Utc::now().to_rfc3339(),
        ))
    }
```

```rust
pub fn assess(&self, project_id: &str) -> Result<AggregateIndexFreshness, AggregateIndexError> {
```

```rust
pub fn rebuild(&self, project_id: &str) -> Result<AggregateIndexRecord, AggregateIndexError> {
    self.with_single_writer(project_id, || {
        let revision = self.logical.load_manifest(project_id)?.ok_or_else(|| missing_manifest(project_id))?.membership_revision;
        match self.build(project_id, revision) {
            Ok(next) => Ok(next),
            Err(error) => {
                self.store.degrade_last_known_good(project_id, error.to_string())?;
                Err(error)
            }
        }
    })
}

pub fn with_single_writer<T>(&self, project_id: &str, operation: impl FnOnce() -> Result<T, AggregateIndexError>) -> Result<T, AggregateIndexError> {
    let path = self.paths.aggregate_index_lock_path(project_id);
    std::fs::create_dir_all(path.parent().expect("aggregate index lock parent")).map_err(io_error)?;
    with_exact_exclusive_lock(&path, operation).map_err(store_error)
}
```

```rust
pub async fn start_streaming(&self, launch: ValidatedStreamingProviderInput, cancel: CancellationToken) -> Result<ProviderSession, ProviderGatewayError> {
    let (input, validated) = launch.into_parts();
    self.revalidate_before_spawn(&validated, &input.working_dir)?;
    let adapter = self.lookup_real_streaming_adapter(&validated)?;
    adapter.start(input, cancel).await.map_err(ProviderGatewayError::adapter)
}

pub fn run_sync(&self, launch: ValidatedAdapterInput) -> Result<AdapterOutput, ProviderGatewayError> {
    let (input, validated) = launch.into_parts();
    self.revalidate_before_spawn(&validated, Path::new(input.worktree_path.as_deref().ok_or(ProviderGatewayError::MissingCwd)?))?;
    self.lookup_real_sync_adapter(&validated)?.run(&input).map_err(ProviderGatewayError::adapter)
}
```

```rust
// src/product/logical_codebase/aggregate_initialization_store.rs
pub fn cancel(&self, project_id: &str, operation_id: &str, request: AggregateCancellationRecord, at: String) -> Result<AggregateInitializationOperation, ProductStoreError> {
    self.update(project_id, operation_id, |operation| {
        if !matches!(operation.status, AggregateInitializationOperationStatus::Created | AggregateInitializationOperationStatus::Running) { return Err(identity_mismatch(operation_id)); }
        operation.cancellation = Some(request);
        operation.updated_at = at;
        Ok(())
    })
}

pub fn recover_interrupted(&self, project_id: &str, operation_id: &str, at: String) -> Result<AggregateInitializationOperation, ProductStoreError> {
    self.update(project_id, operation_id, |operation| {
        if matches!(operation.status, AggregateInitializationOperationStatus::Completed | AggregateInitializationOperationStatus::Failed | AggregateInitializationOperationStatus::Cancelled) { return Ok(()); }
        let step = operation.current_step.ok_or_else(|| identity_mismatch(operation_id))?;
        operation.mark_step_failed(step, AggregateInitializationErrorRecord::interrupted(), at.clone())?;
        operation.status = AggregateInitializationOperationStatus::Failed;
        Ok(())
    })
}
```

取消顺序固定为持久化 cancellation → signal provider Abort → 删除 operation-owned staging → RAII 释放运行租约 → 当前 step/operation 标 `Cancelled`；已 atomic publish 的 digest 完整版本不得猜测回滚。恢复先检查 output receipt/digest，完整则只标完成并等待显式 resume；否则清理 staging、标 `aggregate_initialization_interrupted` 失败，绝不自动重启 provider。集成 fixture 的快照包括每个成员的 HEAD、porcelain status、tracked file list、untracked file list 与 `.git` ref；成功/失败/取消三种流程均比对。aggregate root 可以写 `.aria/aggregate/**`，成员 roots 一字节不得改变。
