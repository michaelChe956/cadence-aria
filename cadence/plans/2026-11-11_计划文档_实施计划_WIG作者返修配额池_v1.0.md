# WIG 作者返修配额池（fix-author-rewrite-quota-pool）实施计划 v1.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 author 重写额度收敛为**单一预算域、单一权威余额**：平台自动重写改扣 B 池（`max_manual_repairs`，初值 3）并与 owner 反馈互扣；自动重写不再消耗 / 不再受限于机械返修池 A（`max_repairs`，上限 1）；扣减与 author 重跑预领同 session CAS、幂等、未委托可退；「编译成功清零」只清编译链上的自动重写段、不清门反馈段。**这是收敛记账口径，不是放宽预算**——任何配额上限逐字不变。

**Architecture:** 沿用既有「total − 已计费 − 活动预留」预算模式（先例 `StructuralGovernanceState::available_user_budget`，`src/product/models/workspace.rs:513`）。核心恒等式：**权威余额 ≡ 门快照净余额（`manual_repairs_remaining`，无快照 ⇒ 总额 3）− 预算域自动段净扣减**——反馈段的预留 / 结算 / 退款 / 显式继续已全部体现在 `manual_repairs_remaining` 的净变动里（每个 reserve 恰好 −1、交付不重复扣、退款回补），故不镜像双记；自动段的新 durable 事实是 session 记录上的 `author_rewrite_budget`（按 provider-start 幂等键记账），与门反馈共用同一 session CAS。**门快照建立 / 重建时**：快照 `manual_repairs_remaining` := 权威余额，且**同 CAS 将自动段结转清零**（消费事实沉入快照、账本清段、`total_ever` 保留）——否则后续读会双计自动扣减。

**Tech Stack:** Rust（`src/`；`#[cfg(test)]` 内联测试 + 引擎集成测试）；session CAS = `with_exclusive_lock` 互斥写（先例 `compare_and_save_policy_route`、`compare_and_reserve_human_gate_turn_in_admission`）；行数门禁 `tests/it_core/large_file_guard.rs`。

**Spec:** `openspec/changes/fix-author-rewrite-quota-pool/`（proposal.md / design.md / tasks.md 39 个工作包 / specs/work-item-plan-single-candidate/spec.md 的 MODIFIED REQ-WSC-21 含 9 场景）；主规格 `openspec/specs/work-item-plan-single-candidate/spec.md:820-846`（REQ-WSC-21 既有 5 场景，**不改**）；串行序唯一权威 `cadence/designs-reviews/2026-11-09_裁决_WIG四change审阅问题处置_v1.0.md` §2.2（本 change = **序 2**）。
