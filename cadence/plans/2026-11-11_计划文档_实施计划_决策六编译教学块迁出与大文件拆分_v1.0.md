## Review Focus

1. **测试静默不再运行**：测试从 `foo.rs` 搬到 `foo/bar.rs` 后，若 `#[cfg(test)]` 门或 `mod` 名变了，测试可能**静默不跑**（用例数减少但无失败）→ 每个拆分都要比对 `cargo test --lib` 的 `N passed` 不得减少。
2. **`include!` 片段跨界 / `mod` 块被劈成两半**：纯文本插入或模块边界切在 `mod xxx { … }` 中间 → 语法错或语义漂移。
3. **可见性放宽过头**：为拆文件把原本私有的项放宽成 `pub` → 扩大公开 API 面，等于改了契约。
4. **`use` 作用域漂移**：`include!` 内联的 `use` 落到宿主模块作用域，与真模块的 `use super::*` 语义不同 → 换机制时可能改变名字解析。
5. **教学重驱 prompt 的调用点断链**：迁出后 `crate::product::workspace_engine::build_work_item_plan_compile_reredrive_prompt` 若不再可解析，作者重驱路径整条断掉 —— 但这种断链**不一定让任何测试变红**，必须单独断言调用点仍可编译且既有重驱单测仍绿。
