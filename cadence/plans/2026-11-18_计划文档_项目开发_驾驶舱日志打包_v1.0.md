# 驾驶舱日志打包实施计划

> **For agentic workers:** 使用 `subagent-driven-development`；逐项验收，不读取真实用户日志。

**Goal:** 下载一次经宿主授权的诊断包，支持第三方分析而不导出会话正文。

**Architecture:** 驾驶舱公共入口 → 实例内一次性授权 → 只读采集与有界事件投影 → 私有文件中完成 tar.gz → 浏览器附件。与控制面登录、provider 执行链和既有 runtime-info 契约隔离。

**Tech Stack:** Axum、Rust（rustix、tempfile、tar、flate2）、React/TypeScript、Vitest。

**Spec:** `openspec/specs/cockpit-log-bundle/spec.md`；已归档的决策与任务位于 `openspec/changes/archive/2026-11-18-add-cockpit-log-bundle/`。

## Global Constraints

- 工作树 `feat/cockpit-log-bundle`；所有临时验证产物在 `/tmp`，不触碰共享服务或真实家目录。Linux/macOS 使用 OS 文件权限；不能证明安全时拒绝，不放宽。
- 授权 5 分钟、每家 3 个不同会话、无远程明文 HTTP、无会话正文选项、无通配下载/上传。包的时间使用 UTC，出口为 gzip 附件。
- 诊断代码集中在 `src/web/handlers/log_bundle/`。除私有子模块引入，既有公开函数签名、provider 的运行时权限和工作区路径计算不变。

## Review Focus

1. 域名/回环反代、无宿主确认、跨 Origin、重放、过期、同 UID 文件读取不能获得批准 → T4。
2. 链接（含父目录）、硬链接、特殊文件、扫描量限制和记录丢失 → T1/T3。
3. Kimi/Claude 子代理、重复会话 ID、并列时间、不足 3 个 → T2。
4. 提示、代码、工具 stdout、嵌套的自由文本或伪装成字段值的令牌污染导出 → T2/T3。
5. 点击取消、重复点击、错误响应误存附件、成功后解包不是本实例数据 → T5/最终验收。

## T3 快照与压缩（工作包 1.1、2.2、4.1）

- [ ] 新 `archive.rs`（测试可独立 `archive_tests.rs`）。`from_host(runtime:serde_json::Value) -> io::Result<std::fs::File>`；内部构造函数允许测试注入 HOME 与四个原生根，不在测试设置全局环境。证实同源 JSON、嵌套 `commands`、缺项、秘密不入会话文件及可解压性。
- [ ] 运行信息由现有 `health::runtime_info(State(...))` 传 `.0`，不二次 HTTP。状态固定 `$HOME/.aria/projects`，限定两种目录。provider 根仅正常 HOME 和已知环境变量（不打开配置）；文件成员 `providers/<provider>/<rank>/<stream序号>.jsonl` 保证多 agent 唯一。`manifest.json` 写版本、UTC、相对成员、每家选中/收录数、固定缺项/裁剪原因、轨迹策略及历史命令不可信提示。
- [ ] 对 Aria JSON 保持相对层次，遮盖常见凭据键；超大或无效 JSON 整个跳过并给出原因。日志读取有界尾窗（每文件至多 8 MiB，不追新增），仅完整、可解析 JSON 行经 `trace::project` 入包。总输入/输出预算 128 MiB，限成员/目录项，写明覆盖是否完整。临时文件完成 gzip/tar 再返回，seek 到开头；只写普通文件头、无绝对路径或属主，禁止原始 JSONL fallback。

## T4 宿主授权、HTTP（工作包 3.1）

- [ ] 新 `permit.rs`：仅内存的 `Grants::default()`、`issue(&self,origin:&str)->io::Result<Ticket>`（`request_id`, `handle`）、`redeem(&self,origin:&str,handle:&str)->bool`，以及从 `src/cli.rs::run_cli_async` 接入的 `approve_local(request_id:&str)`。在短路径 0700 临时目录为本次申请绑定 Unix socket，核验双方 peer UID；普通文件不能代替 socket。宿主本地命令核对 origin/申请号后交互确认；无 HTTP 批准口，不写凭证文件。实例、Origin、5 分钟单次，限制待批请求并到期清理。拒绝未批准/跨源/重放，不读源。验证无 shell/路径注入、并发和过期。
- [ ] 新 `log_bundle/mod.rs` 导出 `routes()->Router<WebAppState>`；`handlers/mod.rs` 声明模块；`app.rs:42` 前合并子路由。`POST /api/diagnostics/log-bundle/authorize` 不扫源，返回 `{request_id, handle, expires_in_seconds:300}`（句柄本身不是批准）；`POST /api/diagnostics/log-bundle/download` 严格 JSON `{confirmed:true,handle}`。两者都要求现有信任门和精确 Origin，对非回环要求受信 HTTPS。任何日志、URL、错误详情都不含句柄。一次性核销后才 spawn_blocking 采集。gzip 附件含时间戳以及 no-store，限制并发。
