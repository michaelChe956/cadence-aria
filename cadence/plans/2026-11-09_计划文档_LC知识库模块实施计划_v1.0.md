# LC 仓管理 · 知识库模块 实施计划 v1.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 LC 仓管理里落地知识库模块：三个按钮（初始化 / 更新 / 查看详细内容），由平台复用聚合初始化的 provider 选择器调用 Cadence-skills 的 `knowledge-base-bootstrap` / `knowledge-base-update`，并在页面上阅读与编辑当前 LC 的知识库文档。

**Architecture:** 新增独立的知识库 operation 模块（`src/product/logical_codebase/knowledge_base/`），复用聚合初始化的 provider 选择器 / gateway / trust 门 / 单飞登记 / 取消语义，**不改动**聚合初始化的五步配方、四条 root recipe 命令与 `AggregateBootstrap` 凭据链。知识库 provider turn 走 **Normal 相位 + `CodingTargetWrite`（target = canonical 聚合根）**，使「选择期判定」与「起跑放行」落在同一行能力矩阵。用户撰写的输入与变更包由平台做**机械可判定**的门禁，语义一致性交回 skill。

**Tech Stack:** Rust（tokio / axum / serde / serde_yaml 或既有 YAML 依赖 / sha2）、React 19 + TypeScript + Vite + TanStack Router v1 + Tailwind、`monaco-editor`（既有，只读变体需扩为可写）、`marked`（既有，渲染）。
