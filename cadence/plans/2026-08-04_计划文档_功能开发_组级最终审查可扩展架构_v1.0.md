# 组级最终审查可扩展架构 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把组级审查从单次全量 Provider 调用改造为「Rust 确定性材料编译 + 分片语义审查 + 全局归约」，使每次 Provider 输入有界且支持 20 个 Work Item。

**Architecture:** 三段式——`GroupReviewMaterialCompiler`（Rust，从权威 Binding 编译不可变快照并完成确定性检查）→ 分片调度器（每片 ≤4 Work Item，确定性分片 + 预算再分片）→ 归约阶段（唯一最终结论）。所有失败按环节重试，门禁单活且按优先级替换。最终结论仍写入既有 `InternalPrReview`，不改 per-unit Renderer Hash。

**Tech Stack:** Rust（tokio 异步、serde、sha2），既有 `authoritative_group_reviewer_bindings` / `parse_review_payload` / `create_blocked_gate` / `sanitize_diff_text`。

**对应契约：** `openspec/changes/scalable-group-final-review/`（commit `e3f7faab`）

## Global Constraints

- 不得修改 `src/product/work_item_projection/render.rs:483-524` 的 per-unit 渲染文本，不得提升 Renderer Version，不得用新材料调用 `bind_unit_run_execution_context`。
- 单位身份快照写入必须幂等；缺失时可从已持久化报告确定性重建。
- 单次 Prompt 质量目标 28 KiB、硬上限 30 KiB；1 KiB = 1024 bytes；硬上限只可收紧。
- 容量超限（>20 Work Item）必须 fail-closed，不回退全量调用。
- 结论转写补救禁止 approve；判定必须有原始输出的标记锚点；finding 描述必须是原始输出子串。
- 历史 Attempt（legacy InternalReviewer hash 有/无）必须都能在新架构下重试。
- 每片 Work Item ≤4；findings ≤8（分片）/ ≤16（归约）；分片并发默认 2。
- Rust 构建/测试命令禁止 `-j 1`；用中文回复，代码用英文。
