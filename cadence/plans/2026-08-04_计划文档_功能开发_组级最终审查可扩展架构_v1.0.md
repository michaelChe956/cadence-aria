# 组级最终审查可扩展架构 实施计划 v2.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把组级审查从单次全量 Provider 调用改造为「Rust 确定性材料编译 + 分片语义审查 + 全局归约」，使每次 Provider 输入有界且支持 20 个 Work Item。

**Architecture:** 三段式——`GroupReviewMaterialCompiler`（Rust，从权威 Binding 编译不可变快照、完成确定性检查、内部分片，finalize 后计算 content_hash）→ 分片调度器（每片 ≤4 Work Item，确定性分片 + 预算再分片）→ 归约阶段（唯一最终结论）。所有失败按环节重试，门禁单活且按优先级替换。最终结论仍写入既有 `InternalPrReview`，不改 per-unit Renderer Hash。

**Tech Stack:** Rust（tokio 异步、serde、sha2），既有 `authoritative_group_reviewer_bindings` / `parse_review_payload` / `create_blocked_gate`。

**对应契约：** `openspec/changes/scalable-group-final-review/`（commit `e3f7faab`）

**v2.1 变更（针对 Plan 第 2 轮评审）：** Task 1 扩展为集中定义所有跨 Task 共享类型（DTO + PromptSegments + 编译辅助），消除 Task 3/4/5 前向编译依赖；compile 注入 ShardPromptMeasurer trait，预算再分片移入 compile 内部、在 content_hash 前完成，消除 finalize 后改 partition_result 的矛盾；归约选取集合恢复跨片 D 级文件（owner 跨片的契约相关文件有明确文件归属，应选取；只有被切断的契约边本身不映射 diff）；Task 6/7a 的 RED 堆叠拆成 RED→GREEN 交替；Task 1 的缺字段测试移到实现前；Task 7b/7c 标注高风险。

**v2.0 变更（针对 Plan 第 1 轮评审）：** 合并原 Task 2+3 消除快照生命周期循环；Task 4 不再依赖未创建的 orchestrator；Task 7 拆为 7a/7b/7c；补齐模块注册、可见性提升、CodeReviewReport 加 unit_run_id、GroupReviewReductionReport 全字段、缺失的 RED 测试。

## Global Constraints

- 不得修改 `src/product/work_item_projection/render.rs:483-524` 的 per-unit 渲染文本，不得提升 Renderer Version，不得用新材料调用 `bind_unit_run_execution_context`。
- 单位身份快照与单项审查报告**在同一事务原子写入**，任一失败整体回滚；缺失快照走身份缺失门禁，重试时确定性重建。
- 单次 Prompt 质量目标 28 KiB、硬上限 30 KiB；1 KiB = 1024 bytes；硬上限只可收紧，质量目标配置值必须小于硬上限。
- 容量超限（>20 Work Item）必须 fail-closed，不回退全量调用。
- 结论转写补救禁止 approve；判定必须有原始输出的标记锚点；finding 描述必须是原始输出子串。
- 历史 Attempt（legacy InternalReviewer hash 有/无）必须都能在新架构下重试。
- 每片 Work Item ≤4；findings ≤8（分片）/ ≤16（归约）；分片并发默认 2 且可配置。
- Rust 构建/测试命令禁止 `-j 1`；用中文回复，代码用英文。

**分片确定性规则（编译内部）：**
- order key = (unit order index, unit_id)；tie-break 用 unit_id 字典序
- 三类亲和边：Handoff 依赖（B.input_contract 消费 A.output_contract）、共享文件（两 unit 完成diff 同一文件）、契约边界（两 unit 引用同一 contract_id）
- 连通分量按内部最小 order key 排序；装箱每片 ≤4；分量 >4 按 order key 稳定切连续 ≤4 组
- 被切断的边进 cross_shard_edges

**变更片段选择器（编译内部，产出 diff_index 与 per-shard 选取）：**
- 完整索引：路径、增删行、owner unit_run、shared/ambiguous/forbidden_scope_hit 标记
- A-E 分级（多级命中取最高，A>B>C>D>E）；owner=完成diff唯一包含该文件的 unit_run，否则 ambiguous
- 分片选取：本片 A/B/C/D + E 文件头；归约选取：A∪B∪跨片 C∪跨片 D（owner 属于不同分片的 C/D 级文件；被切断的契约边本身不映射为 diff，由 global_graph 呈现）
