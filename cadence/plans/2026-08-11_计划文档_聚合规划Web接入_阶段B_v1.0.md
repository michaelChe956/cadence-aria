# 聚合规划 Web 接入（阶段 B）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让多仓库（逻辑代码库）issue 在页面上能完整走「Story → Design → WorkItem → compile」规划链路，Story/Design 阶段 AI 拥有完整聚合视野，产出带 target_repository_id 的单仓 Work Item。

**Architecture:** 方案 X 两阶段创建——HTTP handler 阶段创建草稿态 Spec（放宽校验）+ 注入聚合 prompt；WebSocket AI run 阶段解析 structured output 回写 involved；confirm gate 强制校验。复用既有 PlanningContextResolver、extract_structured_json、aggregate_*_scope_prompt（现 dead_code）。

**Tech Stack:** Rust（axum handlers / lifecycle_store / workspace_engine）、TypeScript/React（前端分组）、OpenSpec。

impl LifecycleStore {
    pub fn update_story_spec_aggregate(
        &self,
        project_id: &str,
        issue_id: &str,
        entity_id: &str,
        scope: &AggregateStorySpecScope,
    ) -> Result<StorySpecRecord, ProductStoreError> {
        validate_relative_id(project_id)?;
        validate_relative_id(issue_id)?;
        validate_relative_id(entity_id)?;
        // 校验 involved ∈ effective_member_ids（Draft 态也校验，防止脏数据）
        for involved in &scope.involved_repository_ids {
            if !scope.effective_member_ids.contains(involved) {
                return Err(ProductStoreError::InvalidRecord {
                    kind: "story_aggregate_scope",
                    reason: format!("involved_repository_not_effective: {involved:?} 不在 effective_member_ids"),
                });
            }
        }
        let mut spec = self.load_existing_spec(project_id, issue_id, entity_id)?;
        // 仅 Draft 态可更新（Confirmed 后锁定）
        if spec.confirmation_status != LifecycleConfirmationStatus::Draft {
            return Err(ProductStoreError::Conflict {
                kind: "story_aggregate_locked",
                id: entity_id.to_string(),
            });
        }
        spec.involved_repository_ids = scope.involved_repository_ids.clone();
        spec.focus_repository_id = scope.focus_repository_id;
        spec.updated_at = Utc::now().to_rfc3339();
        // write_json 回写（路径同 create）
        write_json(&self.story_spec_path(project_id, issue_id, entity_id), &spec)?;
        Ok(spec)
    }
    // update_design_spec_aggregate 同理（含 change_order 字段）
}
```

// src/product/workspace_engine/aggregate_output_parser.rs
use crate::product::logical_codebase::LogicalRepositoryId;
use crate::product::workspace_engine::parsers::extract_structured_json;
use uuid::Uuid;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StoryAggregateOutput {
    pub involved_repository_ids: Vec<LogicalRepositoryId>,
    pub focus_repository_id: Option<LogicalRepositoryId>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DesignAggregateOutput {
    pub involved_repository_ids: Vec<LogicalRepositoryId>,
    pub change_order: Vec<LogicalRepositoryId>,
}

#[derive(Debug)]
pub enum AggregateOutputError {
    MissingStructuredOutput,
    InvalidSchema(String),
}

pub fn parse_story_aggregate_output(content: &str) -> Result<StoryAggregateOutput, AggregateOutputError> {
    let (_, json) = extract_structured_json(content)
        .ok_or(AggregateOutputError::MissingStructuredOutput)?;
    #[derive(serde::Deserialize)]
    struct Schema {
        involved_repository_ids: Vec<String>,
        #[serde(default)]
        focus_repository_id: Option<String>,
    }
    let parsed: Schema = serde_json::from_str(&json)
        .map_err(|e| AggregateOutputError::InvalidSchema(e.to_string()))?;
    let involved = parsed.involved_repository_ids.iter()
        .map(|s| s.parse::<Uuid>().map(LogicalRepositoryId))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| AggregateOutputError::InvalidSchema(e.to_string()))?;
    let focus = parsed.focus_repository_id
        .map(|s| s.parse::<Uuid>().map(LogicalRepositoryId))
        .transpose()
        .map_err(|e| AggregateOutputError::InvalidSchema(e.to_string()))?;
    Ok(StoryAggregateOutput { involved_repository_ids: involved, focus_repository_id: focus })
}
// parse_design_aggregate_output 同模式（含 change_order: Vec<String> → Vec<LogicalRepositoryId>）
```

            // 仅多仓（有 logical_codebase_ref）校验
            if spec.logical_codebase_ref.is_some() {
                if spec.involved_repository_ids.is_empty() {
                    return Err(ApiError::validation("involved_repositories_undetermined", "多仓 Spec 必须有 involved"));
                }
                // Design: involved>1 须 change_order（3b）
                if matches!(session.workspace_type, WorkspaceType::Design)
                    && spec.involved_repository_ids.len() > 1
                    && /* spec.change_order 为空 */ {
                    return Err(ApiError::validation("change_order_required_for_logical_codebase", "多仓 Design 必须有 change_order"));
                }
            }
            lifecycle.update_spec_confirmation_status(/* Confirmed */).map_err(product_store_api_error)
        }
        // WorkItem / WorkItemPlan 分支不变
    }
}
