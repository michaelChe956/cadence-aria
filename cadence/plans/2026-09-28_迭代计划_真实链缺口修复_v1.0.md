> 状态：**已确认并实施完成（2026-09-30 打标）**。本草案经总方案 v1.0→v1.2 收敛为 C1/C2/C4/C5 四个 change（原 Change C 并入 C2），四者已于 2026-09-30 归档，终局关闸三轮予关闸（`cadence/reports/2026-09-30_终局关闸_缺口修复迭代验收_v1.0.md`）。来源：WIG 自动化迭代真实链暴露的 23 项缺口+3 个直写旁路（`cadence/notes/2026-09-27_遗留清单_P1真实链产品缺口_v1.0.md` GAP A-J + `2026-09-28_遗留清单_P3真实链产品缺口_v1.0.md` 发现#1-19）。目标：让 enrolled 全自动链在真实环境端到端可用（上迭代正例仅替身承载的根因全数消除），并把 3 个直写旁路产品化。

## 分组与 change 划分

### Change A：`enrollment-rebinding-and-generation`（enrollment 换代与生命周期）——核心
消除「手工/换代 plan 无法成为合法 enrollment 绑定」的死链（上迭代 enrolled 正例不可达的根因链 #10→#12）：
- **#12 三重恒等**：产品化 plan 换代/重绑通路（显式 supersede+绑定迁移+子会话换代语义；或 enrollment 生成失败后的可重开语义）
- **#14 子会话绑定 mismatch**：finalizer 复用不筛 status/绑定（finalizer.rs:171-177）+绑定恒等校验无解除 API（workspace.rs:541-546）→换代编译必撞
- **#10 author 网关预检**：enrollment Enable 前对 author 做 GAP-F 同构预检（coding 段 coder=author 快照经网关必炸）
- **#16 advance Failed 重试**：`mark_advance_initialization_error` 单向置 Failed 无复位面——瞬时失败（租约冲突）永久卡死 plan
- **#11 租约重取/移交**：死亡 attempt（awaiting_manual_recovery/aborted）不自动释放租约；新 advance 无抢占分诊
- **#6+#1 降级门 feedback 通路**（#1 家族）：SC 返修接力孤儿门/降级门缺反馈通路，只有 abandon 死路

### Change B：`coding-execution-resilience-and-triage`（coding 执行链韧性与分诊产品化）
让 coding 段的真实失败都能走产品面恢复（3 个直写旁路全部产品化）：
- **#5 retired_attempts 无清除**：同进程 abort 过的 attempt 永远无法 RestartCoding（F-44 语义被击穿）
- **#4 分诊后 runner 断头**：manual_continue 后 CodeReview 续跑无覆盖（gate_response 白名单/attach 重启/消息面三处都不管）
- **#13 unit_run 区间退化**：复活重跑零提交时复用陈旧 start 误伤 WIP 提交——按「空区间=零新提交」事实派生
- **#18 spawn/返修渲染不对称**：send_to_coder 门动作对有未消费指令的 attempt 恒自撞（bind 恒等校验 vs 两路径渲染口径不一）
- **#19 验证命令豁免**：字面命令环境不可满足时无人工豁免/计划修订通路（含 unit_run 上下文演进语义）
- **#17 locator 路由+evidence 权限**：政策 locator 无存储路径路由结构性 0 命中；evidence 通道 coder 角色禁用与 read gate 期望不一致
- **#3+#8 WS 生命周期**：临时 driver WS 关闭 supersede 静默丢弃已完成修订产物；返修接力窗口必须常驻 WS
- **#7 reviewer 回退毒配置**：start_generation reviewer 缺省 unwrap_or(author) 对 LC 链必炸
- **#2/#9 文案**：coder 对 node --test 目录形式误诊的提示修正（随 #19）；AC 基线外路径修复文案（#9）

### Change C：`sc-revision-prompt-budget`（小）
- **#15**：SC 人工返修 prompt 32KB 预算分项/提额——大候选（>25KB）门只剩 approve/abandon 二元

### Change D：`logical-codebase-bootstrap-hardening`（LC 基建，GAP A-D）
- GAP-A 双轨解析（v1.3 LC 子树 vs legacy 并存不一致）/ GAP-B aggregate index 鸡生蛋 / GAP-C identity journal 死锁 / GAP-D rules 文件硬依赖前置校验+指引
- 含 GAP-I/J（legacy 布局 enrollment 422=LC-only；如需单仓用户可用自动化则在此扩 routing）
