# 版本更新弹窗（What's New Dialog） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在用户打开工作台（`/workbench`）时，按版本号在 localStorage 去重弹出当前版本的中文更新要点列表，参考 GitHub Releases 的精炼形式，纯前端实现、零后端改动。

**Architecture:** 新增 `web/src/whats-new/` 模块：`changelog.ts` 集中维护手写中文 changelog 数据（`CURRENT_VERSION` + `CHANGELOG` 数组），`useWhatsNew` hook 封装 localStorage 读/写与"是否应弹"判定（不可用时静默降级）。新增受控模态组件 `WhatsNewDialog`，在 `AppShell` 挂载时经 hook 判定是否渲染，关闭即写入已读版本号。发版时人工同步 `Cargo.toml` 版本与 changelog 数据。

**Tech Stack:** React 19、TypeScript、TanStack Router、Tailwind、Vitest、@testing-library/react、jsdom。

## Global Constraints

- OpenSpec 权威来源：`openspec/changes/whats-new-dialog/`（proposal/design/specs/tasks）；本计划逐项覆盖 `tasks.md` 的 1.1–4.1，不得引入后端接口、GitHub API、用户级已读同步或"查看历史更新"入口。
- 纯前端实现，零后端改动；版本号经 ts 模块 `CURRENT_VERSION` 编译期注入，不新增运行时网络请求。
- 去重 key 固定为 `aria-whats-new-seen`，值为版本号字符串；localStorage 不可用时必须静默不弹、不抛错、不阻断工作台。
- 更新内容为人工维护的中文要点列表（`highlights: string[]`），不使用完整 markdown 正文；首版只记录 0.0.5，不回头补更早版本。
- 触发点固定为 `AppShell`（即 `/workbench`）挂载，不在 router/main 更外层。
- 先写失败测试，再写最小实现（TDD）；前端测试用 vitest + @testing-library/react，包管理只用 `pnpm`；前端验证命令为 `cd web && pnpm test`，构建/类型检查为 `cd web && pnpm build`。
- 弹窗视觉沿用现有 Dialog 风格（参考 `web/src/components/image-create/SettingsDialog.tsx`：`fixed inset-0` overlay + `role="dialog"` + `aria-modal="true"`），使用既有 CSS 变量（`--aria-*`）。
- 不自动 add/commit范围外残留；每个 Task 末尾按约定提交。

- `changelog.ts` 导出：
  - `export interface ChangelogEntry { version: string; date: string; title: string; highlights: string[]; }`
  - `export const CURRENT_VERSION = "0.0.5";`

```ts
describe("useWhatsNew", () => {
  beforeEach(() => {
    window.localStorage.clear();
  });

  it("未读当前版本时 open 为 true 并提供对应 entry", () => {
    const { result } = renderHook(() => useWhatsNew());
    expect(result.current.open).toBe(true);
    expect(result.current.entry?.version).toBe(CURRENT_VERSION);
  });

  it("已读当前版本时 open 为 false", () => {

    expect(result.current.open).toBe(false);

  it("close 后写入已读版本号并关闭", () => {
```

```ts
// web/src/whats-new/useWhatsNew.ts
import { useEffect, useState } from "react";
import { CHANGELOG, CURRENT_VERSION, type ChangelogEntry } from "./changelog";

export const WHATS_NEW_SEEN_KEY = "aria-whats-new-seen";

function readSeenVersion(): string | null {
  try {
    return window.localStorage.getItem(WHATS_NEW_SEEN_KEY);
  } catch {
    return null;
  }
}

function writeSeenVersion(version: string): void {
  try {
    window.localStorage.setItem(WHATS_NEW_SEEN_KEY, version);
  } catch {
    /* localStorage 不可用：静默降级 */
  }
}

export function useWhatsNew(): {
  open: boolean;
  entry: ChangelogEntry | null;
  close: () => void;
} {
  const entry = CHANGELOG.find((item) => item.version === CURRENT_VERSION) ?? null;
  const [open, setOpen] = useState(false);

  useEffect(() => {
    if (!entry) {
      return;
    }
    setOpen(readSeenVersion() !== CURRENT_VERSION);
  }, [entry]);

  const close = () => {
    writeSeenVersion(CURRENT_VERSION);
    setOpen(false);
  };

  return { open, entry, close };
}
```
