# 逻辑代码库身份与登记闭环 Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 实现三层身份模型、身份迁移 journal、批量 attach-only 登记，让用户能把 50 个仓登记为逻辑代码库成员。

**Architecture:** 基于 Spike 1 的三层身份 newtype、tombstone ledger 与可重放 migration journal，将旧 `repos.json` 保留为物理兼容投影而非新领域权威。新增 `LogicalCodebaseStore` 管理 manifest/member/checkout/registry/journal，`LogicalCodebaseRegistrationCoordinator` 独立于现有单仓 `RepositoryRegistrationCoordinator::register`，只读取 Git 元数据和写聚合根 `.aria`，不触发 Claude 初始化或 GitFinalize。迁移在项目专属排他锁内按 journal 已持久化 mapping 重放；开启能力开关时新读路径优先逻辑权威，关闭时严格回退既有单仓行为。

**Tech Stack:** Rust, tokio, serde, uuid。

## Global Constraints

- 禁止 `cargo test -j 1`，也禁止给任何 Cargo 命令显式传入 `-j 1`；并行度由 `.cargo/config.toml` 管理。
- 定向单测必须使用 `cargo test --locked --lib <测试名>`，不得省略 `--lib`。
- 登记阶段零 Git 副作用（REQ-REG-02）：不执行 `git add`、`git commit`、`git push`，不操作成员主 checkout。
- 稳定 UUID + tombstone：禁止按 `len + 1`、文件数或 `repo_hash` 分配逻辑身份（REQ-REG-04）。
- 逻辑代码库能力必须由 feature flag 控制；关闭时回退单仓行为，绝不把多仓 work item/attempt 静默映射到其他仓（REQ-REG-08）。
- 迁移的跨文件一致性只可由项目锁、journal mapping idempotency key 与最后 marker 保证；不得宣称跨文件原子事务。
- 所有 ID 在组成磁盘路径前均经 `validate_relative_id` 或 UUID parse 校验；不能用 `repo_hash` 做 source 去重或重定位键。
- 中文回答（项目语言规则）：所有正文、测试名说明、错误 action 使用中文；代码、类型名与命令保持英文。
- 本计划不修改既有 `src/product/repository_store/registration.rs` 的单仓初始化/`GitFinalize` 流程；批量登记使用独立 coordinator。

// src/product/logical_codebase/types.rs：追加到两个 ID newtype 后
use std::path::{Path, PathBuf};

use sha2::{Digest, Sha256};

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct RepositorySourceIdentity {
    pub scheme: String,
    pub key_digest: String,
    pub canonical_git_dir: PathBuf,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub canonical_origin: Option<String>,
    pub first_seen_path_hash: String,
}

impl RepositorySourceIdentity {
    pub fn from_git_parts(
        checkout_path: &Path,
        canonical_git_dir: PathBuf,
        canonical_origin: Option<String>,
    ) -> Self {
        let canonical_origin = canonical_origin.map(|value| value.trim().to_string());
        let scheme = if canonical_origin.is_some() {
            "git_dir_and_origin_v1"
        } else {
            "git_dir_only_v1"
        };
        let origin = canonical_origin.as_deref().unwrap_or("");
        let key_digest = sha256_text(&format!(
            "{}\0{}",
            canonical_git_dir.to_string_lossy(),
            origin
        ));
        Self {
            scheme: scheme.to_string(),
            key_digest,
            canonical_git_dir,
            canonical_origin,
            first_seen_path_hash: crate::product::id::repo_hash_for_path(
                checkout_path.to_string_lossy().as_ref(),
            ),
        }
    }

    pub fn git_dir_identity(&self) -> String {
        sha256_text(self.canonical_git_dir.to_string_lossy().as_ref())
    }
}

fn sha256_text(value: &str) -> String {
    format!("sha256:{:x}", Sha256::digest(value.as_bytes()))
}

pub fn upsert_active(&self, project_id: &str, entry: IdentityRegistryEntry) -> Result<(), ProductStoreError> {
    let mut registry = self.load(project_id)?.unwrap_or_else(|| IdentityRegistry { schema_version: 1, entries: Vec::new(), updated_at: String::new() });
    if let Some(existing) = registry.entries.iter_mut().find(|value| value.source_identity.key_digest == entry.source_identity.key_digest) {
        if existing.source_identity != entry.source_identity {
            return Err(ProductStoreError::Conflict { kind: "source_identity_collision", id: entry.source_identity.key_digest });
        }
        if existing.state == IdentityRegistryState::Tombstoned {
            return Err(ProductStoreError::Conflict { kind: "repository_source_tombstoned", id: existing.physical_repository_id.clone() });
        }
        if existing != &entry {
            return Err(ProductStoreError::IdentityMismatch { kind: "identity_registry", id: existing.physical_repository_id.clone() });
        }
        return Ok(());
    }
    registry.entries.push(entry);
    registry.updated_at = chrono::Utc::now().to_rfc3339();
    crate::product::json_store::write_json(&self.path(project_id), &registry)
}

    let file = OpenOptions::new().read(true).write(true).create(true).open(lock_path)

pub fn ensure_through_authority(&self, project_id: &str) -> Result<(), ProductStoreError> {
    validate_relative_id(project_id)?;
    let lock_path = self.paths.identity_migration_lock_path(project_id);
    std::fs::create_dir_all(lock_path.parent().unwrap()).map_err(|error| ProductStoreError::Io(error.to_string()))?;
    with_exact_exclusive_lock(&lock_path, || {
        let mut journal = self.load_or_begin_scanning(project_id)?;
        self.scan_legacy_repositories(&mut journal)?;
        self.persist_mappings_from_source_identity(&mut journal)?;
        self.write_authority_records(&mut journal)?;
        self.journals.save(project_id, &journal)
    })
}

pub fn delete(&self, project_id: &str, physical_repository_id: &str, command: DeleteRepositoryCommand) -> Result<RepositoryDeletionReceipt, ProductStoreError> {

pub fn resolve_logical_repository(
    &self,
    project_id: &str,
    logical_id: LogicalRepositoryId,
) -> Result<(CodebaseMemberRecord, RepositoryCheckoutRecord, RepositoryRecord), ProductStoreError> {
    self.ensure_identity_schema(project_id)?;
    let authority = LogicalCodebaseStore::new(self.paths.clone());
    if let Some(member) = authority.load_member(project_id, logical_id)? {
        let checkout = authority.load_primary_checkout(project_id, &member)?;
        let repository = self.list_legacy(project_id)?.into_iter()
            .find(|record| record.id == member.physical_repository_id)
            .ok_or_else(|| ProductStoreError::IdentityMismatch { kind: "logical_repository", id: logical_id.0.to_string() })?;
        if repository.logical_repository_id == Some(logical_id) && repository.primary_checkout_id == Some(checkout.checkout_id) {
            return Ok((member, checkout, repository));
        }
        return Err(ProductStoreError::IdentityMismatch { kind: "logical_repository", id: logical_id.0.to_string() });
    }
    self.resolve_legacy_projection_if_dual(project_id, logical_id)
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CanonicalAggregateRoot {
    pub canonical_path: std::path::PathBuf,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AggregateRootPreflightError {
    code: &'static str,
    message: String,
}

impl AggregateRootPreflightError {
    pub fn code(&self) -> &'static str { self.code }
}

pub fn validate(&self, project_id: &str, root: &std::path::Path, candidates: &[std::path::PathBuf]) -> Result<CanonicalAggregateRoot, AggregateRootPreflightError> {
    let canonical_root = std::fs::canonicalize(root).map_err(|error| AggregateRootPreflightError { code: "aggregate_root_missing", message: error.to_string() })?;
    if self.git_probe.is_git_root(&canonical_root)? { return Err(AggregateRootPreflightError { code: "aggregate_root_is_git", message: canonical_root.display().to_string() }); }
    for candidate in candidates {
        let canonical_member = std::fs::canonicalize(candidate).map_err(|error| AggregateRootPreflightError { code: "member_path_missing", message: error.to_string() })?;
        if !canonical_member.starts_with(&canonical_root) { return Err(AggregateRootPreflightError { code: "member_symlink_escape", message: canonical_member.display().to_string() }); }
        if canonical_member == canonical_root { return Err(AggregateRootPreflightError { code: "member_path_outside_root", message: "aggregate root cannot be a member".into() }); }
    }
    self.reject_owned_root_files(&canonical_root)?;
    self.reject_overlapping_manifest_root(project_id, &canonical_root)?;
    Ok(CanonicalAggregateRoot { canonical_path: canonical_root })
}
```

pub fn resume_batch(&self, project_id: &str, batch_id: &str) -> Result<RegistrationBatchRecord, ProductStoreError> {
    let mut batch = self.batches.load(project_id, batch_id)?;
    if batch.status == RegistrationBatchStatus::Cancelled { return Ok(batch); }
    batch.status = RegistrationBatchStatus::Running;
    self.batches.save(&batch)?;
    for item in batch.items.iter_mut().filter(|item| item.status != RegistrationItemStatus::Completed) {
        let revalidated = self.revalidate_candidate(&batch.aggregate_root, item)?;
        if revalidated.preflight_revision != item.preflight_revision {
            item.status = RegistrationItemStatus::NeedsAttention;
            item.failure_reason = Some("preflight_revision_changed".into());
            continue;
        }
        self.attach_batch_item(&batch.project_id, &batch.id, item)?;
    }
    batch.status = aggregate_batch_status(&batch.items);
    batch.retry_count += 1;
    batch.updated_at = chrono::Utc::now().to_rfc3339();
    self.batches.save(&batch)?;
    Ok(batch)
}

    head: Vec<u8>,
    refs: Vec<u8>,
    worktree_list: Vec<u8>,
    config: Vec<u8>,
    hooks: Vec<(std::path::PathBuf, Vec<u8>)>,
    index: Option<Vec<u8>>,
}

impl RepositoryGitSnapshot {
    pub fn capture(root: &std::path::Path) -> Result<Self, ProductStoreError> {
        Ok(Self {
            status_porcelain: git_stdout(root, &["status", "--porcelain"] )?,
            head: git_stdout(root, &["rev-parse", "HEAD"] )?,
            refs: git_stdout(root, &["for-each-ref", "--format=%(refname) %(objectname)"] )?,
            worktree_list: git_stdout(root, &["worktree", "list", "--porcelain"] )?,
            config: std::fs::read(root.join(".git/config")).unwrap_or_default(),
            hooks: read_tree_bytes(&root.join(".git/hooks"))?,
            index: std::fs::read(root.join(".git/index")).ok(),
        })
    }

    pub fn assert_unchanged(&self, after: &Self) -> Result<(), ProductStoreError> {
        if self == after { Ok(()) } else { Err(ProductStoreError::IdentityMismatch { kind: "registration_git_side_effect", id: "git_snapshot_changed".into() }) }
    }
}
```

`git_stdout` 仅允许 `status --porcelain`、`rev-parse HEAD`、`for-each-ref`、`worktree list --porcelain`、`rev-parse --show-toplevel`、`rev-parse --git-dir`、`config --get remote.origin.url`；probe API 对其它 argument 返回 `InvalidRecord { kind: "registration_git_command", ... }`。登记执行不写成员 checkout 的 `.aria`、`.codegraph`、hooks、config、index，也不创建分支/worktree/commit；允许聚合根 `.aria`/`.codegraph`。

// src/product/logical_codebase/registration.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DetectedRepositoryProfile {
    pub repo_type: RepositoryType,
    pub tech_stack: Vec<String>,
    pub initialization_commands: Vec<String>,
}

pub struct RepositoryProfileDetector;

impl RepositoryProfileDetector {
    pub fn detect(root: &std::path::Path) -> Result<DetectedRepositoryProfile, ProductStoreError> {
        let package_json = root.join("package.json").is_file();
        let pnpm = root.join("pnpm-lock.yaml").is_file() || root.join("pnpm-workspace.yaml").is_file();
        let vite = root.join("vite.config.ts").is_file() || root.join("vite.config.js").is_file() || root.join("vite.config.mts").is_file();
        if package_json {
            let mut tech_stack = vec!["package.json".to_string()];
            if pnpm { tech_stack.push("pnpm".to_string()); }
            if vite { tech_stack.push("vite".to_string()); }
            let repo_type = if vite { RepositoryType::Frontend } else { RepositoryType::Library };
            return Ok(DetectedRepositoryProfile { repo_type, tech_stack, initialization_commands: Vec::new() });
        }
        Ok(DetectedRepositoryProfile { repo_type: RepositoryType::Unknown, tech_stack: Vec::new(), initialization_commands: Vec::new() })
    }
}
