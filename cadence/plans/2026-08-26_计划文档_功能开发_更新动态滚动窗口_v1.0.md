# 更新动态滚动窗口 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 更新动态弹窗滚动展示"不高于当前版本"的最新 ≤4 个版本；预置 0.0.9 条目（休眠至发布）。

**Architecture:** 纯前端：`changelog.ts` 加窗口选择函数与预备条目；`useWhatsNew` 输出 entries 数组；`WhatsNewDialog` 多区块渲染。触发/已读/localStorage 降级语义零改动。

**Tech Stack:** React + TypeScript + Zustand-free hook + Vitest。

**Spec:** `openspec/changes/whats-new-recent-versions/`（工作包 1.1-3.1）。

## Global Constraints

- `CURRENT_VERSION` 保持 `"0.0.8"` 不动；`Cargo.toml` 不动。
- 0.0.9 条目日期用占位值并加"发布时替换为真实日期"注释；发布操作（升版本/填日期/裁剪数组至 4 条）由用户手动完成，不在本计划内。
- 展示窗口必须排除高于 `CURRENT_VERSION` 的条目。
- 验证：`cd web && pnpm tsc -b && pnpm test`；`cargo fmt --check`、`cargo clippy --all-targets --all-features --locked -- -D warnings`、`cargo test --locked`（后端无改动，防意外回归）。🔴 禁止 `-j 1`。

**Interfaces:**
- Produces: `export function recentEntries(currentVersion: string, limit = 4): ChangelogEntry[]`（按数组序取首个等于 currentVersion 的下标，向前截 limit 条；找不到当前版本返回 `[]`）。

**Steps（TDD）：**
1. 先写失败测试：changelog 有序性/窗口排除 0.0.9/窗口=4 条（0.0.8..0.0.5）；useWhatsNew 未读时 entries 4 条且首条 0.0.8；Dialog 渲染 4 区块新→旧 + 关闭回调。
2. 跑 `pnpm test -- whats-new` 确认 RED。
3. 实现：changelog 新条目（高亮：①图片创作生成图片改为本地文件存储，历史会话打开不再受 base64 拖累②修复 kimi code 提示词迭代失败）+ `recentEntries`；hook 改 entries；Dialog props `entries: ChangelogEntry[]` 多区块（区块标题=版本+日期，沿用现有卡片样式，区块间分隔线）。
4. `cd web && pnpm tsc -b && pnpm test` 全绿。
5. 后端三件套跑一遍确认零回归。
6. Commit：`feat(whats-new): 更新动态滚动展示最近4个版本并预置0.0.9条目`。
