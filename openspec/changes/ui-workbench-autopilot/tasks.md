# Tasks: ui-workbench-autopilot

**工作包性质**：本文件只登记**高层工作包**与验收口径（映射 `specs/web-workbench-autopilot/spec.md` 的 requirement 与 `design.md` 的决策）。精确文件、命令、测试与提交步骤由 `superpowers:writing-plans` 展开到 `cadence/plans/`；Plan 只能展开工作包，不能重定义契约。

**主契约**：`cadence/designs/2026-09-13_设计文档_3.7UIUX自动执行驾驶舱_v1.0.md`（权威）；本文件的 requirement 编号对应 `specs/web-workbench-autopilot/spec.md`。

**分段纪律**：Phase 1 拆 1a / 1b，各段**独立增量验收、不合并**；每段关闸须同时产出**自动化证据清单**（fake provider + review-fixture 驱动的门开 + 前端单测覆盖三投影与门禁三态、本段新增事件分支、去重键与重连重放幂等）与**人工证据清单**（真实链走查步骤 + 截图、卡壳提醒层级逐层可观察、全程无命令行）。**自动化替身不得代替人工验收**（REQ-UI37-12）。

**全局边界（每工作包均继承）**：只动 `web/src/`；不改后端、不新增接口 / WS 事件 / 持久化、不新增前端依赖；不改 `ImageCreatePage` 页面内容；编码侧不新增插话入口（REQ-UI37-13）。
