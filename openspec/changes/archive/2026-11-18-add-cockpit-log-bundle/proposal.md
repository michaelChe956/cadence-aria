## Why

排查客户现场问题时，逐项打开运行信息、查找初始化回执、辨认各家原生会话容易取错实例或漏掉日志。用户需要一个可先自行检查、再手动发给排错人员或 AI 的下载包。

## What Changes

- 在驾驶舱的「设置」旁增加「日志打包」。仅在人主动操作并授权后，从运行 Aria 的操作系统账号采集；浏览器负责下载，不在服务器的 Downloads 目录代存。
- 保存当前实例的运行信息、家目录 Aria 状态中的两类 JSON 记录，以及四家真实 provider 各自最近三个不同会话的日志；另附机读清单区分实际收录、未找到与无法读取。
- 导出不是控制面的一般只读查询：单凭能访问受信域名不可获取账号会话。既有 API 的访问模型不变。

## Capabilities

### New Capabilities

- `cockpit-log-bundle`：交互式诊断日志下载。

### Modified Capabilities

- 无。

## Impact

涉及驾驶舱设置入口、支持导出处理和原生日志读取。不会安装、探测或调用 provider，不修改现有日志，不采集整个家目录、环境变量或 provider 配置，不自动上传、调用外部 AI 或发版。
