# Tasks: Scalable Group Final Review

## 1. 单位审查结论身份快照

- [ ] 1.1 定义携带 Attempt、Unit、Unit Run、逻辑 Work Item、Work Item Revision、报告标识、结论、发现摘要、证据与变更引用、原始报告哈希的身份快照记录，并落地持久化与读取。
- [ ] 1.2 在单项审查成功持久化的同一流程中生成该快照；缺少快照的历史数据以身份缺失原因失败关闭。

映射 requirement：组级审查材料必须来自权威 Binding。

## 2. 组级材料编译与确定性检查

- [ ] 2.1 实现不可变材料快照：稳定排序、规范化序列化、内容哈希，并定义使快照失效的事实变化集合。
- [ ] 2.2 实现契约与能力精确匹配、写入范围与归属、Commit 与证据一致性、Requirement 与验收标准聚合的确定性检查，输出候选发现与门禁依据。
- [ ] 2.3 实现单位记录与全局账目两级压缩材料，保留身份、依赖、范围、契约接口、证据状态与可路由目标。
- [ ] 2.4 实现变更文件完整索引与按风险的片段选择，含脱敏、安全截断、截断与未展示数量标注。

映射 requirement：组级审查材料必须来自权威 Binding；确定性检查必须在调用 Provider 前完成；变更材料必须提供完整索引并按风险选择片段；分片与归约必须复用同一不可变材料快照。

## 3. 分片编排

- [ ] 3.1 实现按依赖、共享写入范围、契约边界、拓扑层与稳定顺序的亲和性分片，分片上限为 4 个 Work Item。
- [ ] 3.2 实现超过上限连通分量的稳定最小割切分，并把被切断的关系边写入全局跨片关系集合。
- [ ] 3.3 实现分片语义审查的构建、调用与结论持久化，含并发上限与分片结论产物。

映射 requirement：组级审查必须按分片上限切分并逐片审查。

## 4. 字节预算门禁

- [ ] 4.1 实现每次 Prompt 的分段字节度量与记录。
- [ ] 4.2 实现质量目标与硬上限判定：未超目标正常发送、介于两者之间发送并告警、超过硬上限禁止调用并持久化溢出诊断。
- [ ] 4.3 实现单字段超限时的再分片或溢出门禁，禁止截断身份与契约标识。

映射 requirement：单次 Provider 输入必须受字节预算约束。

## 5. 归约与结论合并

- [ ] 5.1 实现归约阶段材料构建与调用，产出唯一最终结论、影响范围、PR 描述与提交信息建议。
- [ ] 5.2 实现结构化指纹的发现合并、严重度取最高与判定规约，禁止文本相似度合并。
- [ ] 5.3 接入既有组级权威目标校验与流程决策，最终结论继续写入既有 InternalPrReview。

映射 requirement：归约阶段必须产出唯一最终结论；发现合并必须使用结构化指纹。

## 6. 失败语义与门禁

- [ ] 6.1 实现未产出结论时的受限结论转写补救，禁止重新包含完整材料、禁止重新审查或新增发现。
- [ ] 6.2 实现材料溢出、分片输出无效、归约输出无效、权威身份缺失四类门禁及互不相同的原因码。
- [ ] 6.3 实现按环节重试与失效传播：分片失败只重试该分片、归约失败只重试归约、返修只失效受影响环节。
- [ ] 6.4 实现目标歧义的无效输出处理与人工门禁。

映射 requirement：失败必须可按环节重试且不得产生通过结论；组级审查的材料与输出失败必须落地可区分的阻塞门禁；组级失败门禁必须提供按环节重试的动作；同一次评审结论只落地一个阻塞门禁。

## 7. 兼容性与验收

- [ ] 7.1 验证既有单项 Reviewer Projection 渲染文本与 Execution Context Hash 不变，历史 Attempt 可在新架构下重试。
- [ ] 7.2 验证三家 Provider 使用同一材料结构、字节预算与结论契约，原始输出始终留存审计。
- [ ] 7.3 建立 20 个 Work Item 的容量验收：5 个分片加 1 次归约，每次输入不超过硬上限，跨片契约错配、跨片共享文件冲突与范围违规均被检出。

映射 requirement：组级材料协议对所有 Provider 一致；组级审查必须按分片上限切分并逐片审查；单次 Provider 输入必须受字节预算约束。
