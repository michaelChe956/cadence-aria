## 范围

新增一个驾驶舱工具，而不是远程日志浏览器。被读取的账号是 **Aria 进程的宿主 OS 账号**，不是浏览器访客；下载路径由浏览器决定。入包的是当前运行信息、`$HOME/.aria/projects` 下指定两类 JSON 和每家最近三个不同会话的诊断日志。无安装探测、任意目录参数或自动转发。

## 授权与用户路径

`设置 ｜ 日志打包` → 了解将收集的内容 → 获取本次授权 → 确认并下载。设置槽与兜底入口共享一个按钮组；沉浸页保持不显示。取消关闭，不采集；执行中不允许重复；错误能看见，成功不把文件长期留在服务器。

控制面今天只验证 Host/Origin。采集必须另验本次宿主授权：申请时只创建一个权限为 0600 的临时授权文件，内有不可猜测的一次性码；网页拿到操作指引，绝不会从 HTTP 拿到码。与 Aria 同机的用户可用文件选择器选择新生成的授权文件；经受信 HTTPS 域名访问时，由运行账号的操作者在主机读取并单独交付本次码。只选授权文件，不选或上传用户的实际日志。一次性码绑定当前实例和精确 Origin，5 分钟有效，原子核销后再碰日志；错误、重放、过期或未启用安全权限均不采集。非回环的明文 HTTP 不接受此流程。授权码不进 URL、持久浏览器存储、日志或归档。

舍弃两种方案：直接受信域名 GET 会把访问来源误当成宿主身份；另做 CLI、常驻 Unix socket 或全站登录，会给仅一次下载引入无关依赖。凭证文件生命周期与实例内有界授权槽绑定，不放到静态资源或被采集目录。

## 归档

- `runtime-info.json` 复用现有 handler 的 JSON 来源，不拼请求头中的域名再请求，也不另算构建信息。该接口本来就含绝对 `workspace_root`，分享提示须明确。
- `aria/projects/...` 保留两种目录树内普通 `.json` 的相对层次（包括回执的 `commands/`）；不遍历整个 HOME，不打包其它状态、配置、锁和链接。
- `providers/<provider>/...` 是诊断用 JSONL。Claude 的根 transcript 建立候选，子代理只附属父会话；Codex 按 rollout 的原生会话头去重，Pi 按 session id，Kimi 按同一 `session_…` 下的 `agents/*/wire.jsonl` 归组。按合规成员最新 mtime 排序，稳定规则打破并列；每家选至多 3 组。
- `manifest.json` 标注版本、UTC 时间、实际来源/相对成员、选中数、收录数、缺项/裁剪和正文策略。把会话中历史命令当作不可信证据，不作为给下游 AI 的指令。

只读普通文件；扫描、单成员字节、总字节数和并发有界。长 JSONL 保留可解析的最近完整事件并如实标记，不把第 4 个会话冒充读取失败的前 3 个。缺目录、权限不足、文件变化和无安全来源可以局部交付；未完成的压缩包不得冒充成功。归档只含相对普通文件、不含所有者信息；通过库创建附件，不运行用户提供的命令。暂存件对其他账号不可读，成功/异常路径均回收。

## 给 AI 的正文选择

已选 **诊断轨迹**：会话只写白名单事件事实（时间、类型、模型、工具类型、退出码、错误类型），不写对话、源码、原始工具入参与输出；未知或无法解析的行不回退为原文。代价是不能分析模型具体措辞。未选「保留脱敏正文」：自由文本掩码找不全秘密，不适合作为转给第三方 AI 的默认材料。
