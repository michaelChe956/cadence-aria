- [ ] 1.1 从与当前实例相同的来源写入 `runtime-info.json`，仅收录允许目录树内的 JSON，包括逐命令回执。

## 2. 原生会话与可读清单

- [ ] 2.1 每家 provider 选择最近三个不同会话，区分子代理和无记录；输出可供 AI 排查的清单及部分失败原因。
- [ ] 2.2 安全打包为一个可解压的 `.tar.gz`，不跟随链接，不读取凭据目录，不泄露无关数据。

## 3. 操作者授权与下载

- [ ] 3.1 在接触本机证据前验证此导出专用的宿主授权；请求不能指定任意来源或输出路径。
- [ ] 3.2 驾驶舱按钮和确认交互：有「设置」时在其旁显示入口；沉浸页不增加入口；待确认可取消；打包中禁重复；失败可见；成功触发浏览器下载。

## 4. 验收

- [ ] 4.1 用隔离 HOME 构造不同时间的会话、嵌套回执、缺失和不安全文件。核对实际归档成员、运行信息与独立授权。
- [ ] 4.2 在真实浏览器从「设置」旁点击「日志打包」，验证取消/确认/下载并解开附件；不读取真实用户会话或改动共享运行实例。
