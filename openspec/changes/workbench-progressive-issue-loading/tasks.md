# 任务清单：工作台渐进加载的界面状态与读取调度

> 精确文件、命令与测试步骤由 superpowers:writing-plans 写入 `cadence/plans/`。本清单只记录高层工作包。

## 工作包

### WP1 — 详情读取的批次隔离

- 需求：`specs/lifecycle-workbench-pipeline-ux/spec.md`「详情读取的批次隔离与焦点保持」场景「新批次不被旧请求阻塞」「旧批次迟到响应不写入新状态」。
- 交付：在途计数随批次生命周期管理；新批次立即可用自己的读取预算；旧批次迟到响应被丢弃。
- 验收：隔离浏览器中挂起旧项目三条详情请求后切换项目，新项目详情立即渲染；旧响应返回后当前项目状态不变。

### WP2 — 待查看态的阶段图与操作入口

- 需求：「紧凑 Issue 队列与阶段 mini-graph」场景「详情未到时的行」「详情到达后迁组并恢复入口」。
- 交付：阶段图新增未知态；待查看行显示四阶段未知态图并保留删除入口；生成 Story Spec 入口在详情到达前不可用。
- 验收：浏览器中待查看行显示四个未知态点、删除按钮可点、生成按钮不可点；详情到达后迁入阶段分组并恢复生成入口。

### WP3 — 加载态与空态分离

- 需求：「既有契约兼容」场景「列表仍在加载时不报空」。
- 交付：队列的加载指示反映议题列表的真实待取状态，而非仅依赖页面级 busy。
- 验收：元数据读取先失败、列表仍在读取时，队列显示加载提示而非「没有匹配的 Issue」；列表到达后显示议题行。

### WP4 — 深链目标失败可见

- 需求：「既有契约兼容」场景「深链目标读取失败有提示」。
- 交付：深链目标详情读取失败时在入口处给出可读中文提示。
- 验收：浏览器中仅深链目标的详情读取失败时，页面出现该提示，后台其它议题的失败不产生提示。

### WP5 — 焦点保持

- 需求：「详情读取的批次隔离与焦点保持」场景「迁组后焦点保持」。
- 交付：议题行跨分组迁移后键盘焦点保持在同一行。
- 验收：浏览器中键盘聚焦待查看行，详情到达使其迁组后，焦点仍在该行标题按钮。

### WP6 — 回归与部署

- 交付：工作台相关测试文件全量通过；前端类型检查通过；构建并部署后，4317 实际加载新产物并通过浏览器复验。
- 验收：四条已复现缺陷在部署后的 4317 上逐条复验通过。
